# 0.1.21 专八、托福与雅思补词记录

日期：2026-10-07。移动版 0.1.21 / Windows 增强补丁 0.1.14。

本版接入了 [OpenEtymology](https://github.com/openetymology/OpenEtymology) 固定提交 `7d89f3697abf26e305fe2627f181b692c2c10b28` 的 TEM8 与 TOEFL 社区词表。上游 [`DATA_LICENSE.md`](https://github.com/openetymology/OpenEtymology/blob/7d89f3697abf26e305fe2627f181b692c2c10b28/DATA_LICENSE.md) 声明公开词表按 CC BY-SA 4.0 发布。项目只抽取小写词头和词表成员关系，不分发来源词表中的释义、例句、词源或音频；成员索引单独保存，并随包提供许可证、归属、提交号和 SHA-256。

第二批从剩余专八、托福、雅思候选中选择该来源有收录、固定 ECDICT 与 KyleBing 对相同中文完整短义和词性一致、本地存在精确拼音候选且有 IPA 的词。逐条人工检查词义后纳入 **136 组新对应、136 个新英文词、136 个中文候选键**。不改变原有译词与中文候选顺序。按新增映射所属标签统计，新增专四2词、专八130词、托福67词、雅思27词；有些词同时属于多个目标，所以分类数不能相加当作去重总数。所有逐词证据与复核说明见 [`10-openetymology-reviewed.tsv`](../vocabulary/data/batches/10-openetymology-reviewed.tsv)。

## 映射覆盖率与拼音可触达率

统计采用固定社区词表成员关系的并集；映射覆盖表示该词至少有一条中英对应。拼音可触达只表示存在完整、精确的本机拼音候选键，不表示它会出现在第一页。以下数据包含 OpenEtymology 新增的专八、托福词表成员关系，故专八、托福分母相较 0.1.20 有变化。

| 目标 | 词表词数 | 已有映射 | 映射覆盖 | 精确拼音可触达 | 可触达率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 四级 | 4,999 | 4,859 | 97.20% | 4,702 | 94.06% |
| 六级 | 6,036 | 5,737 | 95.05% | 5,531 | 91.63% |
| 专四 | 4,340 | 3,978 | 91.66% | 3,827 | 88.18% |
| 专八 | 12,512 | 10,895 | 87.08% | 10,419 | 83.27% |
| 托福 | 12,268 | 9,723 | 79.25% | 9,174 | 74.78% |
| 雅思 | 6,557 | 5,914 | 90.19% | 5,672 | 86.50% |

OpenEtymology 这两份子词表单独统计：TEM8 映射覆盖从 74.15% 提升到 76.96%（3,066 / 3,984），TOEFL 从 90.02% 提升到 91.00%（4,104 / 4,510）。整体并集的专八和托福仍未达到 90%，继续列入后续批次。社区词表不是官方完整考纲，覆盖比例不能解释为官方考试词汇掌握率。

## 可复建文件与许可

- [`openetymology-exam-tags.tsv`](../vocabulary/data/openetymology-exam-tags.tsv)：独立的 TEM8 / TOEFL 词表成员索引，CC BY-SA 4.0。
- [`openetymology-exam-expansion.tsv`](../vocabulary/data/openetymology-exam-expansion.tsv)：本批136组运行映射，逐项依据 ECDICT 与 KyleBing 双来源一致短义/词性，并按 OpenEtymology 名单成员关系筛选；随该词表派生的映射选择表按 CC BY-SA 4.0 提供，保留 ECDICT MIT 与 KyleBing BSD-3-Clause 署名。
- [`openetymology-tags-manifest.json`](../vocabulary/data/openetymology-tags-manifest.json) 与 [`openetymology-expansion-manifest.json`](../vocabulary/data/openetymology-expansion-manifest.json)：固定修订、SHA-256、筛选规则和统计。
- [`OPENETYMOLOGY-DATA-ATTRIBUTION.md`](../vocabulary/data/OPENETYMOLOGY-DATA-ATTRIBUTION.md)：来源、许可与修改说明。
- [`10-openetymology-review-decisions.tsv`](../vocabulary/data/batches/10-openetymology-review-decisions.tsv)：人工选入清单。

两端共用一个初始化一次的本地映射/标签索引，不在按键时扫描源词表或研究词典。完整构建和性能验证以随发布源码及测试报告为准；iOS 需要 Mac/Xcode 才能编译，本版仍只同步源码。
