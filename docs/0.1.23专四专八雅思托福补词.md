# 0.1.23 专四、专八、雅思、托福拼音可达率补充

本版继续补充批次11–12留下的拼音可达缺口。批次13不新增英文词义或考试映射，而是为已有考试译词对应的中文释义增加可靠的本地拼音入口；新增拼音频率为0，因此青简原候选仍排在前面，已有中文候选顺序不变。

批次13从运行词库中已有的考试词义表面扫描候选，最终加入 **407 个新拼音键**，全部由固定 CC-CEDICT、Rime ICE 或两者共同提供的精确词条读音唯一解析；两边同时有记录时，归一化拼音必须完全一致。无法唯一解析或来源冲突的候选不加入。

## 覆盖率

批次12的映射数没有变化。复核时发现，旧的拼音导出统计只覆盖2–6字词面，漏掉键盘实际支持的单字候选；批次12新拼音键还会解锁原始青简词库和此前扩词中的其他释义。0.1.23按实际键盘候选面重算基线，修正没有改动任何英语映射。

## 来源和复建

- [`exam-target-batch-13.tsv`](../vocabulary/data/pinyin-overlays/exam-target-batch-13.tsv) 是运行拼音 overlay；每行注明读音来源。
- [`13-exam-pinyin-reachability.tsv`](../vocabulary/data/batches/13-exam-pinyin-reachability.tsv) 记录每个键的拼音、来源类别、置信规则和示例考试词义。
- [`exam-target-batch-13-manifest.json`](../vocabulary/data/exam-target-batch-13-manifest.json) 固定输入提交、许可证、SHA-256、筛选数量和六类覆盖率。
- [`select_exam_target_batch_13.py`](../scripts/select_exam_target_batch_13.py) 从固定来源确定性重建这批键；用 `python scripts/select_exam_target_batch_13.py --check` 复核。
- 拼音来源分别按 CC-CEDICT CC BY-SA 4.0 和 Rime ICE GPL-3.0 归属；许可原文在 [`vocabulary/data`](../vocabulary/data/) 中分文件提供。

查询时继续使用已经构建好的 QJ 拼音索引，不解析来源词表或下载数据。批次13只在该索引中追加407个低频键；中英释义索引、考试标签数量、现有候选排序都不改动。
