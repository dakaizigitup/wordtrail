# 词伴 Android 0.1.42 公测指南

这是一版供真实手机、平板试用的 Android 公测包，不是应用商店正式版。下载页面：

https://github.com/dakaizigitup/wordtrail/releases/tag/v0.1.42

## 安装

1. 在发布页的 Assets 中下载 `wordtrail-0.1.42-debug.apk`，不是源码 ZIP。文件约 244 MiB（255,445,562 字节），已包含离线语音模型。
2. 用手机文件管理器打开 APK。系统提示时，允许当前浏览器或文件管理器安装此来源的应用；安装后可关闭这项权限。
3. 已安装同签名词伴测试版的用户直接覆盖安装，不用卸载或清除数据。首次安装打开“词伴输入法”，依次启用键盘、切换到词伴；系统显示第三方输入法提示属于正常授权过程。
4. 支持 Android 8.0+、64 位 ARM 手机/平板及 x86_64 模拟器，不支持仅 32 位的设备。建议预留约 1 GB 空间用于安装和首次准备语音模型。
5. 若聊天软件把附件改成 `.apk.1`，在文件管理器中将后缀恢复为 `.apk` 再安装。若出现签名不兼容，请记录旧版来源和错误提示再反馈，不要先卸载丢失学习数据。

## 这次更新

- 扩大 26 键触摸区，A/L 两侧缩进和按键小缝可以点击；支持小幅手指滑动和双指交错输入。
- 九键按音节逐段筛选拼音，可以回退、重选，保留尚未选定的剩余输入。
- 搜索、发送等动作键适配输入框；改善数字键盘、选区删除和组合表情删除。
- 英文补全与中文释义、英语音标和考试标签；空格不会擅自接受拼写纠错。
- 支持 `lambda/lamda` 等名称输入希腊字母，以及 `123 → 符号 → 希腊` 面板。
- 补充 `en → 嗯` 等常用入口；覆盖升级时加载新版词库，保留个人学习数据。

英文能力是本地单词补全和词典查询，不是整句翻译。默认语音在本机处理，不上传或保存录音；可选系统语音服务可能联网。输入习惯保存在本机，私密输入不学习。应用不自动上传公测日志。

## 建议测试

| 场景 | 请关注 |
| --- | --- |
| 26 键连续输入 | 快速连点、A 左侧、L 右侧、按键间隙、轻微移动是否漏字或误触 |
| 九键 | `64426` 输入“你好”、逐段选音、回退、剩余输入、切换全键 |
| 候选与布局 | 展开候选后键盘让位、选词后恢复；手机/平板、横屏、系统大字体下是否裁切 |
| 长按 | 大小写/数字/符号选择、滑选和移出取消是否符合预期 |
| 英文与符号 | `comp` 补全、`helo` 拼写建议、`hello` 中文释义、`lambda` 候选和希腊面板 |
| 中文与学习目标 | `en` 展开后能否选“嗯”；四六级、专四专八、托福雅思多选及多标签显示 |
| 语音 | 授权、首次模型准备、说话后“完成”上屏、取消；有文字预览时不能误报没听清 |
| 不同输入框 | 聊天发送、浏览器搜索、多行换行、数字/电话框、选区和组合表情删除 |
| 覆盖安装 | 设置和学习习惯保留、新增英文词库生效 |

模拟器已通过 70 项本版检查（触摸区 33、长按 7、快速中文 6、快速英文 3、输入框行为 21），证据见 [验证记录](evidence/android-0.1.42-verification.json)。模拟器结果不能代表所有真机手感、耗电或第三方应用兼容性；本次公测重点收集这些反馈。

手写、滑行输入、表情面板及完整学习统计仍未实现。Windows 继续提供原有 0.1.23 补丁；iOS 仅提供未编译、未真机验证的源码。

```text
Android 版本：
使用的应用及版本：
九键/26键；横屏/竖屏；键盘高度/底部留白设置：
操作步骤（包含实际输入的字母/数字）：
期望出现什么：
实际出现什么：
是否每次出现，重新打开键盘后是否仍出现：
截图或录屏（可选，请遮住私人信息）：
```

GitHub Issue 是公开的，请勿粘贴密码、聊天记录、手机号或其他私人内容。没有问题也欢迎反馈机型以及已测试的功能，方便记录兼容范围。
