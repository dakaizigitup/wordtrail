# 0.1.24 专业词汇首批

日期：2026-10-07。批次14为专业词库的第一段，涵盖计算机、商务、医学三类。中文候选与原有排序保持不变，用户可分别选择专业领域和考试目标，让对应英文译词优先显示。

## 本段新增

专业标签来自固定的 Kaikki/Wiktionary 中文—英文快照。只有完整英文译词与运行词库中的某个中文释义精确匹配、且该中文键存在于青简真实拼音候选面时，才加入领域标签。固定快照及 Wiktionary 上游文件均记录 SHA-256；标签索引、逐条证据和复建脚本按 CC BY-SA 4.0 署名。数据只提取词面对应和主题关系，不复制定义、例句或音频。

## 索引与选择

Rust 共享内核在启动时一次性读取新增的分类索引；按英文词面精确查询，键盘每次查询不扫描研究 CSV 或 Wiktionary SQLite。六个考试目标仍占原位 0–5，计算机、商务、医学追加使用位 6–8，因此既有用户设置无需迁移。多选时只把命中目标的英文译词前移，组内顺序稳定，中文候选不变。

本段接受的许可和来源记录在 [`WIKTIONARY-ATTRIBUTION.md`](../vocabulary/data/WIKTIONARY-ATTRIBUTION.md)。逐词决策见 [`14-professional-reviewed.tsv`](../vocabulary/data/batches/14-professional-reviewed.tsv)，实际候选对应和来源 sense ID 见 [`14-professional-domain-evidence.tsv`](../vocabulary/data/batches/14-professional-domain-evidence.tsv)，输入散列与运行数据校验值见 [`professional-vocabulary-manifest.json`](../vocabulary/data/professional-vocabulary-manifest.json)。构建可由 [`build_professional_vocabulary.py`](../scripts/build_professional_vocabulary.py) 离线复现。

下一段继续扩大计算机和商务词汇，并逐项寻找许可明确的来源；新增头词、已有词新增中文对应和既有词新增分类标签将分别统计。
