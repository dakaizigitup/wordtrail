# 0.1.11 四六级补词测试报告

日期：2026-10-06。Android 0.1.11（versionCode 12），Windows 增强补丁 0.1.4。iOS 共用源码和工程版本同步，未编译/真机验证。

## 数据与词义

- 批次01新增2,033组对应，其中309个英文词此前没有任何中文映射；累计3,628组，原1,595组逐条与同中文内部顺序保留。
- 223组重点核对新增；其余自动校验中文完整短义项、同词性和WordNet同义关系。自动验证不能保证排除全部多义词歧义，不宣称全量人工审校。
- 四级映射4,660/4,999（93.22%）、六级5,326/6,036（88.24%）；去重缺口829个。覆盖率是固定社区词表的释义映射统计，不是全部拼音候选触达实测。
- 输出确定性重建、所有旧对应保留、上限与去重、长解释/括号/子串边界、原表无词性条目保留、独立覆盖重算与缺口集合检查通过。
- `python scripts/prepare_cet_batch.py --check` 校验当前输出与固定输入重建结果相同。
- 扩词文本96,859字节，SHA-256：`8ce49a7d511601d1ac337c689541b95b7bbce08c013ea0bc0e859be5337955c4`。

## 性能与包体

同一Windows主机、debug C ABI，6组拼音×3种目标，共18组；每组预热30次、测180次。统计包含本地候选状态、扩词、标签、音标和JSON解码，不包括系统按键到屏幕绘制，也不是实体安卓设备延迟。

- 更新前各组p95：0.6743–2.4832ms；更新后：0.8019–2.8176ms。
- 各组p95的中位数：1.62345ms → 1.49605ms。个别组会上下波动，不据此宣称扩词后更快。
- 首次会话创建单次样本：233.68ms → 194.60ms，包含词库加载和初始化，不能作为稳定冷启动对比结论。
- APK新增114,688字节，约112KiB；14个原词库/IPA/语音模型和语音本地库载荷逐字节相同。
- APK签名v2/v3与16KiB ZIP对齐通过；versionCode12、versionName0.1.11；只有录音权限，没有INTERNET权限。

运行时仍是一份精简中文键索引，不载入或扫描研究词典。新增义项会增加少量查音标、组装状态的工作；长期扩词继续按同一口径测量。

## 证据与交付

证据保存在 `docs/evidence/0.1.11-*`；计数和完整源校验保存在 `vocabulary/data/expansion-manifest.json`。新增差异和逐词缺口在 `vocabulary/data/batches/01-*`。普通构建无需重新下载研究源词典。
