# Android 0.1.40 输入习惯检查

以用户给出的输入法截图、[vivo九键/全键输入说明](https://www.vivo.com.cn/instructions/index?androidVersion=1.0&funtouchVersion=1.0&modelName=PD1945&modelNameExt=vivo+Y9s&pageId=68187&scrollTop=)、[Android输入法开发规范](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method)为参照，检查日常操作是否符合输入框与键盘的预期。vivo不同机型和版本界面有差异，本次没有声称复刻某个版本的全部功能。

## 本轮修正

| 操作 | 原问题 | 0.1.40行为 |
| --- | --- | --- |
| 搜索、发送、前往、下一项、完成 | 一直显示回车图标；英文直输时没有执行应用动作 | 读取输入框声明，显示对应文字并执行动作；支持应用自定义动作标签 |
| 有未完成拼音时按动作键 | 容易误解为已经发送 | 显示“上屏”，先结束本次输入，再恢复发送/搜索；多行框继续使用换行 |
| 删除选中文字 | 只删除光标周围字符的接口不能删除选区 | 优先删除选区，保留两侧文字；中文与英文直输共用实现 |
| 删除表情 | 逐Unicode码点删除会拆散组合表情 | 按系统字符边界删除，覆盖家庭、肤色、旗帜、组合音调字符 |
| 数字输入 | 十个数字挤在一行，和符号混排 | 三列数字键盘；小数框提供英文小数点与符号，电话框提供 `+ * #` |
| 数字框的键盘类型 | 可切到不适用的字母布局 | 遵循数字框限制，保留删除和完成/下一项动作 |
| 九键左侧读音 | “重选”占用顶部候选空间 | 当前拼音优先显示，全部重选放到列表末尾；上一步继续保留 |
| 持续删除与输入框切换 | 收起界面时缺少统一停止处理 | 输入界面结束时停止连删；重新定位光标仍保留不学习标记 |

删除接口语义依据 [Android InputConnection](https://developer.android.com/reference/android/view/inputmethod/InputConnection)：周围删除不包括选区，因此先处理选中文字；组合字符使用系统 ICU 字符边界。

## 已有功能检查范围

九键/26键切换、逐段拼音、候选展开替换按键、选词后恢复、长按大小写/数字/符号、触感反馈、底部留白与高度调整、三套主题、英日西语释义及英语音标均继续沿用。验证使用独立测试应用模拟搜索框、聊天动作、网址、数字、电话和密码框，不操作用户的真实聊天。

## 后续仍可完善

- 空格滑动移动光标、独立文本编辑面板。
- 用户主动打开的剪贴板面板、符号分类和表情面板。
- 手写输入、更多纠错规则和整句输入质量。

这些是后续工作，没有将未实现项写成已完成。本版输出本地Android测试包；不同vivo/iQOO真机的导航栏、震动和应用定制输入框仍需复核。
