# 0.1.13 词汇补充与交付测试报告

日期：2026-10-06。Android 0.1.13（versionCode 14），Windows增强补丁0.1.6（适用于青简Windows 0.1.4）。iOS只同步共享源码，未编译、未真机验证。

## 数据与回归

- 批次02本版增补198组、178个此前没有中文映射的英文词；累计230组、220个真实拼音候选键。逐项证据和排除原因在 `vocabulary/data/batches/02-evidence.tsv`。
- `prepare_candidate_batch.py --apply --check` 重建一致。固定四级映射覆盖从4,660/4,999到4,738/4,999，六级从5,326/6,036到5,489/6,036；去重缺口797降至651。精确拼音候选可触达率为90.66%和86.46%。
- Rust词汇库、移动内核与Windows服务单元测试19项通过（3+7+9）；四六级批次测试8项通过；真实拼音内核对全部230组新增逐条验证候选、词性、译词标签及精确上屏；原生内核回归17项通过。
- Windows隔离真实服务IPC检查35项通过，覆盖既有输入、考试目标热加载、批次00/01与02代表译词、译词轮换及提交；中文候选顺序保持。
- 本机没有连接Android手机或模拟器，故没有真机安装、触屏或设备查询延迟结果。键盘和语音交互代码本轮未改动。

## 查询性能

同一Windows主机、相同debug C ABI和18组固定查询（6个拼音×3种考试目标），每组180次热态状态查询；采样包括本地候选、扩词、标签、音标及JSON返回，不代表按键到屏幕绘制延迟，也不代表Android设备。

| 指标 | 批次02更新前 | 批次02更新后 |
| --- | ---: | ---: |
| 初始化（单次样本） | 196.84 ms | 196.74 ms |
| 18组p95中位数 | 1.763 ms | 1.634 ms |
| 18组p95范围 | 0.773–3.049 ms | 0.909–2.518 ms |

样本中没有持续性查询延迟上升；样本规模有限，不据此宣称普遍加速。逐组数据见 `docs/evidence/0.1.13-performance-before.json` 和 `...-after.json`。
