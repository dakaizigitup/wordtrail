# 0.1.8：英语学习目标与多标签

Android 0.1.8 / Windows 补丁 0.1.2。支持四级、六级、专四、专八、托福、雅思六类，可手动多选。

## 使用

Android：打开词伴首页，找到“英语学习目标”，勾选一个或多个目标。返回输入框即可生效，设置在覆盖升级和重新启动后保留。不选目标或点“全部词汇 / 清除目标”时，英文译词保留原顺序。可单独关闭候选里的考试小标记，详情仍保留标签。

候选小标记缩写：四=四级、六=六级、专4=专四、专8=专八、托=托福、雅=雅思；`+N` 表示另外 N 个标签。手机窄候选显示一个，较宽候选最多显示两个。点小箭头、向下滑候选或点标签可展开详情，竖向滚动查看每条译词的完整标签、词表来源及英式/美式音标。详情中“输入译词 …”按钮可选择原先排在后面的译词。

Windows：解压 0.1.2 补丁，结束正在输入的拼音后运行 `install.cmd`；支持官方青简 Windows 0.1.4 和本项目原 0.1.1 音标补丁。运行 `settings.cmd`，多选目标后点“保存”，约一秒后生效。设置文件独立位于 `%APPDATA%\Qingjian\wordtrail-vocabulary.json`，不改青简的 `config.toml`。候选译词旁显示所属考试标签及音标；Ctrl + 数字仍输入排在首位的译词，原第二译词快捷键对应新的第二条。`rollback.cmd` 恢复此次安装前的服务程序和音标文件，学习数据不改动。

iOS：键盘扩展源码的 ◐ 菜单新增“英语学习目标（可多选）”；同步候选标签、译词排序及详情。未在 Mac/Xcode 上编译或真机验证，没有 IPA。

## 规则

- 中文候选排序、编号和点选输入不改变；只调整同一个中文候选内部的英语译词。
- 多选采用“命中任一目标即可优先”，同组继续保留原顺序。
- 原先的非目标译词仍保留，未收录的词不猜标签；短语不会因为包含一个考试词就被标为该考试词。
- 排序移动完整释义，词性、读音、熟悉度、CEFR、音标和长按上屏保持对应。日语/西班牙语不套用英语考试标签。
- 考试类别和 CEFR 分开：专八词表也可能收录简单词，考试标签不等于难度或个人水平。
- 当前释义数据最多两条，“仍保留”指不丢掉这些已有译词，不代表列出词典里的所有意思。

## 数据与构建

使用固定版本 ECDICT（MIT）及 KyleBing/english-vocabulary（BSD-3-Clause），仅提取词条和类别，不复制其释义、例句、图片或音频。17,865 个去重条目，其中 10,861 个带多个类别；带来源位掩码的索引为 248,545 字节，约 243 KiB。

| 标签 | 去重收录条目 |
| --- | ---: |
| 四级 | 4,999 |
| 六级 | 6,036 |
| 专四 | 4,340 |
| 专八 | 12,410 |
| 托福 | 12,213 |
| 雅思 | 6,557 |

这些是所用社区词表的合并数量，包含部分短语，不是官方完整考试范围；各类别有交集，不能直接相加。某个中文词没有目标类别的现有译词时，保持正常释义，不强塞无关的考试单词。

构建脚本 `python scripts/prepare_vocabulary.py --download` 会先核对所有输入 SHA-256，再归一化、去重、保留多来源并生成确定性索引。完整来源、固定提交、输入/输出校验和在 [vocabulary/data/manifest.json](../vocabulary/data/manifest.json)，许可原文在同目录。普通用户无需自行下载开发词表。

运行时启动工作线程只加载一次 HashMap，按键过程不扫描 CSV 或联网。切换目标只变更位掩码，不重装拼音或音标库。新版保留已有离线语音、三主题、收起按钮、逗号位置与快速点击处理。

## 验证范围

本版的最终安装包、自动检查结果和性能范围见 [0.1.8 测试报告](0.1.8测试报告.md)。

共享 Rust 测试和真实完整词库的 C ABI 测试验证：多标签、精确词面匹配、目标优先与稳定顺序、中文候选不动、对应音标/等级/上屏、第二译词输入、旧快照拒绝、非法类别不覆盖现有选择及非英语不显示考试标签。

Windows 同时验证目标文件启动加载、热加载、非法 JSON/类别保留上次设置、删除目标文件恢复默认，以及真实服务的候选窗口和中文/译词上屏。Android 界面、手机/平板布局和快速连续点击的实际检查结果记录在同版本测试报告与 evidence 中。

主机性能记录包含完整词库查询、音标、CEFR、标签、JSON 返回与解析；不能把它当手机真机响应时间。没有可连接的用户手机/平板或 Mac，本次手机行为以指定 Android 模拟器为验证范围。

后续再增加计算机、医学、商务等专业类别和额外来源校对，不将这些尚未接入的类别标为已支持。
