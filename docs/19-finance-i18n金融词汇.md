# 商务与金融词汇补充：批次19

本批从 MIT 许可的 [finance_i18n](https://github.com/hotvulcan/finance_i18n) 英中词表中筛选会计、贸易、证券、税务、财产和合同语境候选。固定提交为 `98a75886853e586c55896878bfab88e1161f50df`，原始 README 和 MIT 许可均保留在源码中。

上游没有说明这份词表更早的出处，且混有泛用词，因此本批没有整库导入。491组候选同时满足本地拼音、英式/美式 IPA、ECDICT 精确中文义项与词性；341组映射已存在。逐项审阅后新增47组中英映射，其中12个是此前没有的新英文词头；商务标签新增41个词项。103组未映射候选不纳入运行索引，逐项决定和理由留在审校表中。

新增映射覆盖金融、会计、税务、贸易、房地产及合同术语，例如 `devaluation → 贬值`、`disbursement → 支付`、`dumping → 倾销`、`exchequer → 国库`、`redemption → 赎回`。中文候选顺序保持不变；商务标签只影响用户选择商务类别后的英文译词顺序。

运行数据仅含47行短映射和对应标签，不包含上游长解释。来源边界、快照散列、全部候选和审校决定见[来源说明](../vocabulary/data/FINANCE-I18N-ATTRIBUTION.md)、[`19-finance-i18n-reviewed.tsv`](../vocabulary/data/batches/19-finance-i18n-reviewed.tsv)、[`19-finance-i18n-candidates.tsv`](../vocabulary/data/batches/19-finance-i18n-candidates.tsv)及[`finance-i18n-manifest.json`](../vocabulary/data/finance-i18n-manifest.json)。本批不计算或宣称覆盖完整金融专业词表。
