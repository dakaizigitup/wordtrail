# 0.1.7 暖色图标更新

采用原创“奶油小书灵”：杏桃色书封、奶油色书页、可可色圆眼睛和珊瑚色腮红。内置 imagegen 生成，完整设计规格保存于源码的 `branding/设计记录.md`。

- 安卓桌面图标与应用首页 48dp 标识同步更换；适配圆形、方圆形启动器裁切，提供各密度备用图。
- 保留原包名、签名及本地数据，安装 `wordtrail-0.1.7-debug.apk` 即可覆盖升级，不需要卸载。
- 苹果源码补齐 AppIcon 资源目录和首页小图标；这台 Windows 环境未编译、未验证 iOS。
- 键盘、词库、等级和语音流程沿用 0.1.6。

交付位置：`D:\soft\英语输入法\手机版`，提供新版 APK、对应源码 ZIP 和单独 PNG 图标。安装后桌面若暂时显示旧图标，关闭重新打开桌面或重启手机，让桌面缓存刷新。

0.1.7 验证结果另存 `evidence/android-0.1.7-branding.json`；0.1.6 的完整功能测试记录保存在 `evidence/android-0.1.6-report.md`。
