# 0.1.17 测试报告

日期：2026-10-06。移动端版本 0.1.17（Android versionCode 18），Windows 音标增强补丁 0.1.10。

## 本批变更

批次02新增7组经过逐条审校的 Wiktionary 中文义项映射。7组都能从现有拼音候选输入，具有词性、考试标签和随包英语音标；选择目标只提升对应英文译词，原中文候选次序和已有译词保留。四六级去重未映射词由512降到505，扩词累计4,004组。该覆盖率按固定社区词表统计，不代表官方考纲完整覆盖。

| --- | --- |

| `cargo test --locked --offline --workspace` | 26项通过：移动接口3、音标3、词库11、Windows服务9 |

Android 构建时没有连接 Android 设备或已启动的模拟器（`adb devices` 为空），所以本版没有声称通过真机 UI 验收。手机/平板界面交互代码没有改动；新增词条由共享内核测试及 Windows 实际输入服务覆盖。iOS 共享源码已同步，本机没有 Mac/Xcode，未编译验证。

## 响应时间与产物

在本机 Windows debug 共享 C ABI 上，以实际词库、标签排序、音标查询和 JSON 解码执行9组查询组合；每组预热后测量300次。当前复测的 p95 最大8.28 ms，p99 最大9.48 ms。该数字仅描述本机共享接口，不代表 Android 手机延迟；完整测量值见 [`0.1.17-expansion-performance.json`](evidence/0.1.17-expansion-performance.json)。

Android APK 为252,299,621字节，SHA-256：`04433bab098fc3678599bbc83092e6fd40eae58c65c31e977d1e35a38e984da7`。Windows 补丁服务为11,330,560字节，SHA-256：`ba55c5d9fb619935704dd8a205d88bea6732ef6ae32bdf39d813e1a0f513fa6f`。本机安装结果确认原始用户数据未改变，补丁目录保留回滚备份。

Windows 逐项窗口/IPC 结果见 [`0.1.17-desktop-tests.json`](evidence/0.1.17-desktop-tests.json)，安装后校验见 [`0.1.17-desktop-installed-tests.json`](evidence/0.1.17-desktop-installed-tests.json)。六类考试词库覆盖口径、候选审计和后续批次安排见[补词记录](0.1.17四六级补词.md)与[分批补词计划](分批补词计划.md)。
