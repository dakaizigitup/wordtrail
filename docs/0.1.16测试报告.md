# 0.1.16 数据补充测试报告

日期：2026-10-06。Android 0.1.16（versionCode 17），Windows 增强补丁 0.1.9（用于青简 Windows 0.1.4）。

## 数据与查询验证

- 第二段新增66组 CC-CEDICT 映射；批次构建器逐项校验固定源行、整词定义、ECDICT 词性、考试标签、拼音候选键、英美音标及来源许可。四项数据构建测试通过。
- `cargo test --locked --offline --workspace`：25项 Rust 测试通过，覆盖共享词库索引、考试标签、原译词保留和低频词条查询。
- 共享 C ABI 真实词库测试：7项通过；“投掷 → hurl”验证低频词的实际拼音输入、译词优先、CET6/TOEFL 标签、音标及精确上屏。
- Windows 真实候选窗口与 IPC：313项检查通过，含本段66个词逐条可达、译词轮换时中文候选不重排以及逐条提交。测试使用刚编译的 Release 服务；若复测，先运行 `scripts/build_desktop.ps1`。
