# Windows 英音 / 美音补丁 0.1.7

用于本机已安装的青简 Windows 0.1.4。它是独立开发的增强补丁，非官方发布。只替换候选窗口服务程序，增加独立英语音标库、六类考试标签及实际扩词；保留原输入法 DLL、中文词库、原释义表、用户配置与学习记录。

支持从本项目 0.1.1–0.1.6 补丁覆盖升级。运行补丁目录的 `settings.cmd` 可多选四级、六级、专四、专八、托福、雅思目标，保存后约一秒生效。只调整英文译词，中文候选顺序不变；原有译词保留。详细说明见 [0.1.8 词汇目标](0.1.8词汇目标.md)。

## 安装与使用

1. 先结束正在输入的拼音，双击 `install.cmd`。Windows 会要求管理员授权，因为程序安装在 `C:\Program Files\Qingjian`。
2. 脚本核对原程序版本和补丁哈希，备份原程序到同目录 `backup/`，替换并重新启动服务。
3. 用 **Win + 空格** 选择青简输入法；偏好设置的学习语言选英语。
4. 输入 `nihao`，先不要按空格：“你好”的英文释义旁会显示“英 /…/ 美 /…/”。点候选或空格仍输入中文，原有 Ctrl + 数字快捷键仍只输入译词。
5. 安装结果见 `install-result.json`。如需恢复原版，双击 `rollback.cmd`；保留整个补丁目录以便恢复。

音标来自随包独立词典，147,488 个词条，全程本地查询。英式 RP、美式 GA 各自标注；只具备一个地区数据时仅显示该地区，缺词不猜测。保留来源提供的多种发音，没有按词性或句意选择其中一种。目前没有发音音频。

桌面端对各条英语释义分别查音标；安卓及苹果源码显示第一条英语释义的音标，并标明对应单词。日语、西班牙语仍显示原释义。

## 验证与限制

已在本机编译并运行真实 Windows 候选窗口，验证协议 7、中文候选、纯译词上屏、中文上屏；实际窗口截图为 `desktop-ipa.png`。补丁不改动用户数据文件。

此测试程序没有官方数字签名，清单的 UIAccess 为 false。普通桌面窗口已验证；管理员窗口及特殊系统界面的候选层级尚未实测。测试前请保留原版备份。此补丁是 Windows 版本，未提供 macOS 安装包。

随包 `NOTICE.txt` 和 `LICENSE` 保存许可说明。GitHub 汇总发布的 [完整对应源码](https://github.com/dakaizigitup/wordtrail/releases/download/v0.1.14/wordtrail-0.1.14-source.zip) 包括 Windows 补丁、`desktop/`、`pronunciation/`、共享词库、上游与第三方依赖，同时提供手机版源码。Wiktionary 的15条派生中英词条另附 CC BY-SA 4.0 署名和逐条固定修订记录；见压缩包 `data-license/`。历史补丁仍可通过 Releases 下载。

0.1.7 随批次02追加15组经逐条审核的中英对应，总计3,873组；四级/六级映射覆盖率为94.92%/91.17%，仍有636个去重词未映射。按精确拼音候选统计的可触达率为91.78%/87.76%。本批来源授权与修订记录独立随包交付。译词仍按所选考试目标优先，中文候选顺序保持不变，原译词全部保留。一行最多显示两条译词，`Ctrl+Alt+候选序号` 轮换；原第一/第二译词快捷键会输入当前显示的对应译词。输入新的拼音时恢复目标排序。如自定义已把 Ctrl+Alt 配给译词输入或删词，既有设置优先，该组合不轮换。
