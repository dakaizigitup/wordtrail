# Windows 英音 / 美音与词汇目标补丁 0.1.24

用于本机已安装的青简 Windows 0.1.4。它是独立开发的增强补丁，非官方发布。更新候选窗口服务程序和派生中文拼音词库，并增加独立英语音标库、六类考试目标、六类专业领域目标及实际扩词；原始词库、输入法 DLL、原释义表、用户配置与学习记录保留。

支持从本项目既有补丁覆盖升级。运行补丁目录的 `settings.cmd` 可多选四级、六级、专四、专八、托福、雅思，以及计算机、商务、医学、行政学、教育、心理学目标，保存后约一秒生效。只调整英文译词，中文候选顺序不变；原有译词保留。详细说明见 [0.1.8 词汇目标](0.1.8词汇目标.md) 和 [专业词汇首批](0.1.24专业词汇首批.md)。

## 安装与使用

1. 先结束正在输入的拼音，双击 `install.cmd`。Windows 会要求管理员授权，因为程序安装在 `C:\Program Files\Qingjian`。
2. 脚本核对原程序、词库版本和补丁哈希，备份原程序、派生词库与音标库到同目录 `backup/`，替换后重新启动服务。
3. 用 **Win + 空格** 选择青简输入法；偏好设置的学习语言选英语。
4. 输入 `nihao`，先不要按空格：“你好”的英文释义旁会显示“英 /…/ 美 /…/”。点候选或空格仍输入中文，原有 Ctrl + 数字快捷键仍只输入译词。
5. 安装结果见 `install-result.json`。如需恢复原版，双击 `rollback.cmd`；保留整个补丁目录以便恢复。

音标来自随包独立词典，147,488 个词条，全程本地查询。英式 RP、美式 GA 各自标注；只具备一个地区数据时仅显示该地区，缺词不猜测。保留来源提供的多种发音，没有按词性或句意选择其中一种。目前没有发音音频。

桌面端对各条英语释义分别查音标；安卓及苹果源码显示第一条英语释义的音标，并标明对应单词。日语、西班牙语仍显示原释义。

## 验证与限制

已在本机编译并运行真实 Windows 候选窗口，验证协议 7、中文候选、纯译词上屏、中文上屏；实际窗口截图为 `desktop-ipa.png`。补丁不改动用户数据文件。

此测试程序没有官方数字签名，清单的 UIAccess 为 false。普通桌面窗口已验证；管理员窗口及特殊系统界面的候选层级尚未实测。测试前请保留原版备份。此补丁是 Windows 版本，未提供 macOS 安装包。

随包 `NOTICE.txt` 和 `LICENSE` 保存许可说明。配套完整源码包 `wordtrail-0.1.31-source.zip` 包括 Windows 补丁、`desktop/`、`pronunciation/`、共享词库、上游与第三方依赖，同时提供手机版源码。各来源数据分别保留逐行来源及适用许可，补丁压缩包 `data-license/` 会附词条清单、校验哈希和许可原文。历史补丁仍可通过 GitHub Releases 下载。
