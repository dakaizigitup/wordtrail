# 0.1.12 四六级补词：批次02首段

Android 0.1.12（versionCode 13）与 Windows 增强补丁 0.1.5 同步新增32个四六级词条；适用于青简官方 Windows 0.1.4。iOS 同步共享词库源码，未编译或真机验证。

## 本轮新增

本轮新增 **32组中英对应、32个此前没有中文映射的英文词**，分布在31个中文键。每一组都满足：英文词出现在固定四六级社区词表；ECDICT 与 KyleBing 固定版逐项给出相同的中文短义和词性；中文词面确实存在于固定青简拼音候选表。词性按英文义项保存，中文原词性不同的情形单独人工核对，原有中文和英文释义不覆盖。

输入“燃烧”“现代化”“中立”“灌溉”等中文键，可查询 `combustion`、`modernize`、`neutrality`、`irrigation`。这批词继续使用本地精简索引；没有在按键时扫描 CSV、JSONL 或 WordNet。用户选择考试目标后，中文候选顺序不变，目标英文译词参与原有优先排序。

固定数据对照共找到127组同词同义项。85组中文释义不在拼音候选库，当前不会作为不可输入的译词打包；其余冲突项也没有因“词表有收录”而自动采用。逐项来源、拼音、词频与处置记录见 `vocabulary/data/batches/02-manifest.json` 和重建报告。

四级、六级之间有重复词，不能把各自缺口或新增数量相加成去重数。上表“有映射”只表示完整英文词面至少有一组中文义项，不表示所有原有译词都能从拼音候选触达，也不代表官方完整考纲覆盖。固定目标词表来自社区项目；标签是收录关系，不代表难度或考试保证。

累计扩词从3,628组增加到 **3,660组**、从2,647个增加到 **2,664个中文词面**；原有数据、同中文键顺序和每键8条扩词上限均保留。完整新增行见 `vocabulary/data/batches/02-additions.tsv`，797个待补英文词及原因见 `vocabulary/data/batches/02-pending.json`。

## 来源与验证

复用固定提交的 ECDICT（MIT）与 KyleBing/english-vocabulary（BSD-3-Clause），并校验各源文件 SHA-256。新增译词清单单独记录在 `02-reviewed.tsv`；许可全文、来源提交和词表统计在 `vocabulary/data/`。构建报告也固定了实际拼音词库校验和及导出候选清单的校验和。

Windows、Android 共用同一 Rust 词汇索引；键盘中文候选、译词展示和用户学习数据机制没有改变。测试细节、包体大小、签名与 SHA-256 见 [0.1.12测试报告](0.1.12测试报告.md)。

本报告是批次02第一段，不宣称补完四六级词表。后续继续核查可触达别名、剩余词性和短语；严格交叉检查无法确认或拼音候选中缺失的释义保留在待补队列。
