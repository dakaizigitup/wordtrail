# 0.1.14 四六级补词：Wiktionary 审核小批

Android 0.1.14（versionCode 15）与 Windows 增强补丁 0.1.7 同步更新本机英语译词；两端共享同一份增补数据。iOS 同步共享源码，未在 Mac/Xcode 编译或真机验证。

## 本批新增

批次02的固定来源与拼音候选审计之后，仍有651个去重四六级词未映射。本次从 English Wiktionary 的固定修订页面筛选，逐条核对页面中的中文翻译、词义、词性、ECDICT 短义、拼音候选和随包 IPA，新增15组中英对应、15个此前未映射的英文词，分别可通过15个既有中文候选键输入。四级标签命中7词，六级命中14词；同一词可同时属于两类，因此分类计数会重叠。

开始新来源筛查前，也把固定 ECDICT 与两份考试词表的完整7–12字中文短义做了交集审计，结果为0组，不从长解释里截子串凑译词；可重复运行 `scripts/analyze_long_glosses.py`。

纳入的对应为：附属→auxiliary、衰退→downturn、流利→fluently、非常→immensely、行距→leading、大主教→metropolitan、移民→migrant、郊外→outskirt、大部分→predominantly、悲哀→sadness、造船→shipbuilding、下跌→slump、竟然→surprisingly、第三→thirdly、任何→whatsoever。准确词性、目标标签、对应 Wiktionary 修订 URL、页面 ID、修订时间和逐条复核备注见 [`03-wiktionary-reviewed.tsv`](../vocabulary/data/batches/03-wiktionary-reviewed.tsv)。

## 授权与边界

本批英文维基词典的选定内容使用 CC BY-SA 4.0 许可。署名为 English Wiktionary contributors；本项目把固定版本的英汉对应筛成小批，按词性和中文拼音候选整理成紧凑 TSV。NOTICE 中提供署名、许可链接、修改说明以及全部原始词条修订链接。运行文件 [`wiktionary-expansion.tsv`](../vocabulary/data/wiktionary-expansion.tsv) 与对应审校记录独立于 ECDICT MIT 和 KyleBing BSD-3-Clause 数据；本批许可不会替换旁边代码和其他来源数据的许可。

来源与授权：[English Wiktionary](https://en.wiktionary.org/wiki/Main_Page)、[CC BY-SA 4.0 条款](https://creativecommons.org/licenses/by-sa/4.0/)。Wiktionary 页面将词条文本另行提供于 GFDL；本项目按 CC BY-SA 4.0 选项分发所选数据。
