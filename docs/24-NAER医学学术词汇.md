# 批次24：NAER 医学学术名词

批次24从國家教育研究院的《醫學學術名詞》开放数据集中筛选本机可输入的医学译词。来源于台湾主权 AI 训练语料库的数据集页面，发布/更新时间为2026-06-24，许可为政府资料开放授权条款第1版。许可允许重制、散布、改作和再授权，但要求明确署名；本项目按要求保留来源、版本和许可声明。

固定快照包含30,797条英中记录。筛选要求单个英文词面有本地英/美音标和 ECDICT 名词词性，中文能由本地拼音输入，且词条未超过每个中文键的译词容量。繁体转简体后，共得到745组未重复的本地可达新对应：591组连接已有英文词头，本批暂不审查；154组连接136个新英文词头，进入逐项审查。最终接受57组，排除12组，暂缓85组。接受词包括 `anastomosis → 吻合`、`aneurism → 动脉瘤`、`neoplasm → 肿瘤`、`stenosis → 狭窄` 和 `transfusion → 输血`；57个对应也新增57个可多选的医学标签成员。

运行时只读取编译后的精简 TSV，不载入完整资料集。选中“医学”目标后，命中的英文译词优先显示，中文候选次序不变。医学术语没有固定完整分母，因此本批只报告筛选/审查数量，不把这些数字说成对整份数据集或医学词汇领域的覆盖率。

来源 CSV 每行的「來源網站」目前都是字面占位值 `[url]`，无法逐词外部追溯；这点已写入署名和构建清单。完整来源、许可文字、快照散列、每条接受/排除/暂缓理由和确定性构建命令见 [NAER 署名说明](../vocabulary/data/NAER-MEDICAL-ATTRIBUTION.md)、[构建清单](../vocabulary/data/naer-medical-manifest.json) 与 [逐项审校表](../vocabulary/data/batches/24-naer-medical-reviewed.tsv)。Windows 电脑版仍未打包或安装。
