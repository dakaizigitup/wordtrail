# Android 0.1.9：只保留考试标签

候选行、可滚动详情以及设置页均移除 A1、A2、B1、B2、C1、C2 参考等级。不再提供“候选显示英语等级”开关；即使旧版本开启过，也不会重新显示这些等级。

保留四级、六级、专四、专八、托福、雅思六类考试标签，可多选，同词可有多个标签。学习目标、优先英文译词、中文候选原顺序、音标、原有第二译词与输入方式继续沿用。操作方法见 [0.1.8 词汇目标说明](0.1.8词汇目标.md)。

直接覆盖安装 `wordtrail-0.1.9-debug.apk` 即可，学习目标和用户学习数据无需重设。Windows 补丁仍为 0.1.2，本来就未显示 A1–C2，不需要再次升级。iOS 同步移除界面显示的源码，无 Mac，未编译或真机验证。

共享引擎为旧客户端保留原有等级 JSON 字段及数据，不作为本版界面标签显示；数据来源和许可继续保留。以前版本的说明和截图属于历史记录。

本版验证记录见 [Android 0.1.9 检查结果](evidence/android-0.1.9-ui-tests.json) 和 [布局检查](evidence/android-0.1.9-layout-tests.json)，检查范围为 Android 模拟器，真实 vivo/iQOO 手机和平板尚待试用。

最终检查：11 项界面检查、72 项布局检查（4 种尺寸）通过；覆盖安装成功，旧等级开关仍为 true 时也不显示等级。APK v2/v3 签名及 16 KiB ZIP 对齐通过，详见 [构建记录](evidence/android-0.1.9-build.log) 和 [安装包记录](evidence/android-0.1.9-report.json)。
