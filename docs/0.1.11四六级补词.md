# 0.1.11 四六级补词（批次01）

对应 Android 0.1.11 / Windows 增强补丁 0.1.4；iOS 共用源码同步，未编译验证。

本轮新增 **2,033 组中英对应**，涉及 1,539 个英文词，其中 **309 个词此前整个原释义＋0.1.10 扩词表均没有映射**。其他词得到更多中文对应或义项，不能全部算成新的去重英文词。223 组对应来自词伴重点核对；其余按完整中文词义、词性与 WordNet 同义关系自动验证，不宣称全量人工审校。

累计扩词为 **3,628 组对应、2,647 个中文词面**，其中 924 个英文词在最初原释义表中没有。旧版 1,595 组扩词全部保留，同一中文下旧扩词的先后顺序也保留。

## 怎么用

Android 同签名覆盖安装新版；Windows 解压新补丁后运行 `install.cmd`，支持由旧补丁 0.1.1–0.1.3 升级。现有用户设置和学习数据保留。不要把 Windows 增强补丁 0.1.4 与青简官方基础版 0.1.4 混淆。

在首页或 Windows 的 `settings.cmd` 手动选择四级、六级，可多选；只调整英文译词优先级，中文候选顺序不变。同组保持原顺序，所以原词也命中目标时，不保证新增词自动排第一。查看完整译词：Android 展开候选并滚动，Windows 使用 `Ctrl+Alt+候选序号` 轮换；可输入当前显示的第一/第二条。

输入“分析”可在原 analyze 之外查看 analysis；“发展”增加 development；“自由”增加 freedom / liberty；“缺席”增加 absence。新增的名词义项明确带 n.，不会把原动词义项的词性改掉。英式/美式音标来自现有独立音标库，缺失时不猜测。

## 维护与重建

固定已发布基线：`batches/00-expansion.tsv` / `00-manifest.json`。本轮核对输入：`01-reviewed.tsv`；新增差异：`01-additions.tsv`；累计随包数据：`english-expansion.tsv`。

```powershell
# 已准备固定源词典并导出真实 packed glossary 后
python scripts/prepare_cet_batch.py
python scripts/prepare_cet_batch.py --check
```

每个中文词仍最多附加8条，原释义不删。运行时只嵌入 96,859 字节（约95 KiB）的精简扩词表，索引初始化一次，不在按键时扫描研究 CSV、JSONL 或 WordNet。来源提交、校验和、覆盖率和各批数量见 `vocabulary/data/expansion-manifest.json`。
