# Android 0.1.42：26键触摸范围

修复按键间空隙、A 左侧和 L 右侧缩进不能响应触摸的问题，以及轻微滑出键帽边缘时丢掉点按的问题。

## 行为

- 保留 26 键的视觉间距、第二行缩进和原有高度设置。
- 每个按键使用独立的透明触摸容器，包含键帽及其左右/上下间距；第二行两端的缩进分别并入 A、L。
- 相邻触摸区连续、互不重叠。系统手势区和键盘下方抬高留白不转成字符键，候选栏仍走原有点选逻辑。
- 使用 Android `TouchDelegate` 的范围与移动容差；手指还在本键触摸区内时，小幅滑动不再取消点按。按键触发次数、长按选项、取消语义不变。
- 每个触摸容器独立接收事件，由 Android 分指派发支持双指交错输入。向按键转发前复制事件，避免坐标改写影响另一根手指。
- 数字、符号、九键等页面沿用原有布局；本次扩展作用于全键盘的三行字母和底栏。

技术参考：[Android TouchDelegate](https://developer.android.com/reference/android/view/TouchDelegate)。实现见 `android/app/src/main/java/org/wordtrail/ime/KeyHitBox.java`。

## 验证

`tests/test_key_hit_areas.py` 使用实际触摸事件验证手机、平板和横屏下的 A/L 缩进、Q/W 与 A/S 间隙、行间边缘、轻微滑动，并检查双指、取消和从空隙长按滑选符号。快速连点回归使用实际 DOWN/UP 注入，再检查输入框文字，不以点击计数替代结果。

最终结果与包校验见 `docs/evidence/android-0.1.42-*.json`。测试环境为 Android 35 x86_64 模拟器，安装包包含 arm64-v8a/x86_64；用户手机触屏上的实际手感仍需实测。

同签名旧版可直接覆盖安装，无需清除个人词频或重新准备语音模型。
