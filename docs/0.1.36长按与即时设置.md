# Android 0.1.36 长按选字与即时设置

用户反馈：参考输入法的长按字母/数字/符号选字条尚未实现，首页从九键改回26键、修改键盘高度时，已经打开的键盘没有响应。

## 修改

- `WordtrailIME` 注册并保留设置监听，销毁服务时解绑。键盘布局、按键高度、底部留白修改后立即重新布局，避免只在 `onStartInputView` 中读取设置。主题、学习语言、词汇目标与标签开关也随设置同步。
- 布局、高度、留白选项只更新该选项组，不再重建整个首页或夺走试打输入框的焦点；调整高度和留白保留未完成拼音。切换布局清空未完成拼音，保留已提交内容。
- 首页只有首次打开键盘时主动滚动到试打框，修改键盘高度不再将正在操作的设置页面拉走。
- 新增长按键：短按输入主键，长按仅打开选择条；九键显示大写字母、数字、小写字母，26键显示字母与对应数字/符号，字母右上角给出提示；标点键也可长按。
- 不移动时松手输入高亮默认项，滑动后松手输入所选项，取消手势或移出有效区域则不输入。选字条按系统显示后的实际屏幕坐标判断滑选，兼容屏幕边缘调整位置的情况。返回键、收起键盘或改变布局时关闭选择条。
- 增加移动内核的 `literal` 操作：长按选择的字母直接输入大小写原文，不进入中文拼音组合，不切换输入模式；若已有拼音，则先提交当前首选中文，再输入选定字符。保留私密输入状态。

参考 API：[Android 设置变化回调](https://developer.android.com/reference/android/content/SharedPreferences.OnSharedPreferenceChangeListener)、[PopupWindow](https://developer.android.com/reference/android/widget/PopupWindow)、[系统长按时长](https://developer.android.com/reference/android/view/ViewConfiguration#getLongPressTimeout())。弹出条在输入法窗口内显示，无需悬浮窗权限。

## 验证与交付

使用 Android 35 独立模拟器，通过实际首页操作修改已打开键盘的设置；使用触屏 DOWN/MOVE/UP/CANCEL 事件验证长按默认项、滑选大写/小写字母、数字、符号、取消和已有拼音的处理。测试代码为 `tests/test_key_options_v36.py` 与 `tests/android/WindowProbe.java`。重复验证快速触控输入，确保增加长按判断后不漏键。

构建版本为 Android 0.1.36 / versionCode 37，开发签名兼容已有词伴测试版本。测试证据与校验和以最终报告为准。未连接用户的 vivo/iQOO 真机。

最终验证：68项即时设置/长按检查、44项四种尺寸/字体布局检查、6组快速触屏输入及7项移动内核测试通过。签名与16KB对齐检查通过。校验和：`c6d09d05805d5e6bbfbb4aa528b6cb0efcda98ea0d9c50a5af756061493e36bb`。APK大小 253,626,725 字节。
