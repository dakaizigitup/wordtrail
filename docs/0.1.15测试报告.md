# 0.1.15 数据补充与发布验证

日期：2026-10-06。Android 0.1.15（versionCode 16），Windows 增强补丁 0.1.8（用于青简 Windows 0.1.4）。iOS 同步共享词库源码；没有 Mac/Xcode，未编译或真机验证。

## 词库结果

- CC-CEDICT 首段新增58组、58个此前未映射英文词和57个拼音候选键；每条均命中固定考试标签、固定 IPA，并可由拼音候选查询。66条低频人工初审项暂列后续批次。
- 四级/六级映射率分别由94.92%/91.17%升至95.40%/91.98%；精确拼音候选可触达率由91.78%/87.76%升至92.26%/88.57%；剩余578个去重缺口。
- 运行数据单独保存为 vocabulary/data/cccedict-expansion.tsv，2,569字节，SHA-256：cfa15cc83f27bb9115018d797fc27067691491e580ff888640b646ae3e08e063。不重打包原始 CC-CEDICT；许可证、固定快照和审校记录写入 APK、Windows NOTICE 与源码包。
- 所有词条在两端共享索引中按中文精确查询；原中文候选顺序不变，考试目标仍只重排英文译词。新增词条均带已有音标和考试标签。

## 测试

- cargo test --locked --offline --workspace：24项 Rust 单元测试通过。
- CC-CEDICT 数据审校测试：3项通过；确定性构建结果与清单散列相符。
- 共享 C ABI 扩词测试：6项通过，其中“环境 → ambient”验证了实际拼音候选、译词目标优先、标签、IPA 与准确上屏；同一基准下的性能样本见 [0.1.15性能记录](evidence/0.1.15-performance-after.json)。
