## 为什么只纳入7组

从固定 Kaikki/Wiktionary 中文释义快照扫描六类考试词表缺口，随后按同词性 ECDICT 释义、现有精确拼音候选键和已打包 IPA 筛选，共得到87组自动候选、涉及85个词面。自动匹配仍会遇到多义、地域用法、词性差异和同形字误配；只有确认固定 Wiktionary 修订里的具体义项与目标英文词吻合后才纳入。本批还检查了 `allergic → 敏感`、`grammatical → 合法`、`literally → 物理` 等自动命中项，因义项过宽或脱离使用语境而暂缓。

Kaikki 派生 SQLite 快照只用于寻找候选，不复制进应用。每个采用项都在审校表中给出 English Wiktionary 页面、修订 ID、时间和人工说明；本段的运行映射及审校表独立按 CC BY-SA 4.0 提供。来源署名、修改方式和精确数据散列见 [`WIKTIONARY-ATTRIBUTION.md`](../vocabulary/data/WIKTIONARY-ATTRIBUTION.md)、[`wiktionary-manifest-2.json`](../vocabulary/data/wiktionary-manifest-2.json) 和 [`06-wiktionary-zh-reviewed.tsv`](../vocabulary/data/batches/06-wiktionary-zh-reviewed.tsv)。Wiktionary 说明其词条文本采用 CC BY-SA 4.0 和 GFDL 双重许可；本项目选择 CC BY-SA 4.0，并保留归属、许可链接、修改说明及固定修订链接。[许可说明](https://en.wiktionary.org/wiki/Wiktionary:Copyrights)

## 覆盖变化

扩词总量从3,997组增加到4,004组。四六级社区词表有中文映射的词数如下：

| 指标 | 0.1.16 | 0.1.17 |
| --- | ---: | ---: |
| 四级映射覆盖 | 4,801 / 4,999（96.04%） | 4,804 / 4,999（96.10%） |
| 六级映射覆盖 | 5,608 / 6,036（92.91%） | 5,612 / 6,036（92.98%） |
| 四级可由2–6字精确拼音键触达 | 4,620 / 4,999（92.42%） | 4,623 / 4,999（92.48%） |
| 六级可由2–6字精确拼音键触达 | 5,353 / 6,036（88.68%） | 5,357 / 6,036（88.75%） |
| 去重四六级未映射词 | 512 | 505 |

完整拼音键统计另包括单字候选，0.1.17 四级和六级可触达率分别为92.96%和89.56%；这个口径与0.1.16报告的2–6字键不同，不能直接对照。本段新增键都是双字词，历史口径下分别增加3个四级词和4个六级词。

扩展到六类社区词表后，当前映射覆盖率为：四级96.10%、六级92.98%、专四86.15%、专八77.04%、托福70.36%、雅思82.31%。这些词表有大量交集；数字描述固定社区词表有至少一组中文映射，不代表官方考纲完整覆盖。六类完整拼音候选键的可触达率和散列见 [`wiktionary-manifest-2.json`](../vocabulary/data/wiktionary-manifest-2.json)。

六类候选审计仍有自动命中的记录待人工复核。剩余四六级缺口也继续分批检查；不能为追求更高百分比而把模糊译义直接加入键盘。
