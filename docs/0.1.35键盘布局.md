# Android 0.1.35 键盘布局改版

以用户提供的九键候选截图为主要参照，参考[搜狗输入法官方交互说明](https://main.qcloudimg.com/raw/document/product/pdf/1655_81582_cn.pdf)的候选右侧展开、返回键盘、左侧读音筛选与重输机制，并查看 [Fcitx5 Android](https://github.com/fcitx5-android/fcitx5-android) 的候选和主题设计。保留词伴自己的译词、音标与主题，不声称与某一商业版本逐像素一致；没有复制这些项目的源码或素材。

## 布局与操作

- 工具栏保留拼音、学习语言、语音、九键/全键、主题与收起键盘。选词翻页移入展开面板，底栏不再挤入布局切换按钮。
- 候选卡固定为中文、译词两行，保留可选的简写标签，多个标签用 `+` 提示；点标签或译词查看全部标签、音标和来源。没有释义的候选不显示空详情箭头。
- 修复旧版 46dp 候选卡容纳三行造成的裁字。新卡默认 54dp，随系统字体大小适当增高，中文使用实际字体测量高度。
- 候选展开在原按键区和候选条的总高度内呈现，手机四列、宽屏六列；两栏分别滚动，底部提供上一页、下一页、删除、返回键盘。选完词后恢复按键。
- 音标详情、语音界面也在按键区域内切换，不再额外堆叠高度。Android 返回键先关闭这些面板。
- 九键提供左侧读音/标点、中央九键与空格、右侧删除/重输/切换键盘/回车。数字符号页也可删除。重输仅清理未提交内容，并保留隐私模式。
- 默认底部留白从 4dp 增至 16dp，独立提供 4/16/28dp 三档，系统导航区另行适配；横屏自动降为 4dp。按键高度仍独立可选。平板内容宽度上限为 900dp，居中显示。
- 保留稳定输入窗口与按下即输入机制，避免候选出现时改变字母键位置。

## 验证

使用独立 Android 35 模拟器测试 1080×2400 / 420dpi 手机、同规格 1.5 倍字体、2560×1600 / 240dpi 平板、1920×1080 / 440dpi 横屏。测试脚本为 `tests/test_keyboard_layout_v35.py`，记录输出到 `build/keyboard-layout-v35.json`，截图在 `docs/screenshots/v35-*.png`。覆盖候选文字边界、展开等高、隐藏按键、系统返回、音标详情、九键选词/重输/删除、数字删除与已提交文本保护。

快速触控测试使用 `tests/test_rapid_typing.py`，分别从无候选/已有候选状态，以 120/60/30ms 间隔注入真实触屏事件，核对完整输入。共享内核的 7 项 Rust 测试含九键输入、本地学习及重输隐私保护。

测试结论以最终构建与报告为准；未连接用户的 vivo/iQOO 真机，厂商导航栏和实际手感仍需真机复核。本版仅更改 Android 布局及其移动输入会话，不更新或安装 Windows 输入法，不发布 GitHub Release。

最终结果：44 项布局、6 组快速触控、5 项最终界面冒烟、10 项收起/麦克风检查均通过；Rust 7 项通过。最终包 versionCode 36，APK v2/v3 签名和 16KB 对齐有效。
