# 0.1.14 四六级补词批次验证

日期：2026-10-06。Android 0.1.14（versionCode 15），Windows 补丁 0.1.7（适用于青简 Windows 0.1.4）。iOS 仅同步共享词库源码与署名文件；未在 Mac/Xcode 编译或真机验证。

## 数据和输入检查

- 固定构建器重建一致：新增15组中英对应、15个新英文词、15个既有拼音候选键；四级命中7词、六级14词；未映射的四六级词由651降至636。完整输入、输出散列和覆盖率见 `vocabulary/data/wiktionary-manifest.json`。
- Rust 工作区测试23项通过；词库批次测试10项通过，覆盖15条固定修订、标签、IPA、候选触达与逐词上屏；共享 C ABI 回归17项通过。
- Windows 隔离服务 IPC 测试65项通过，其中本批15个词逐个检查拼音候选、译词展示和准确提交。考试目标热加载与译词轮换不改变中文候选顺序。
- Wiktionary 15条来源修订、CC BY-SA 4.0 链接和修改说明已写入 APK 与 Windows NOTICE；Windows 发布包另带完整逐词审校 TSV。Android 两个 ABI 的本机库都包含新增词和来源标记。

## 性能抽样

相同 Windows 主机、debug C ABI、6个固定拼音 × 3种学习目标，每组先预热再执行180次状态查询。该指标包含候选、译词、IPA、标签和 JSON 序列化，不是每次物理按键到屏幕绘制的耗时，也不代表 Android 实机延迟。

| 指标 | 0.1.13 | 0.1.14 |
| --- | ---: | ---: |
| 会话初始化（单次冷样本） | 196.74 ms | 193.56 ms |
| 18组各自 p95 的中位数 | 1.63 ms | 2.01 ms |
| 各组 p95 范围 | 0.91–2.52 ms | 1.10–4.67 ms |

这是少量主机热态抽样，0.1.14的 p95 中位数高约0.38 ms，范围也较宽；现有数据不足以判定稳定的性能回退或改善。新增数据本身679字节，运行继续使用初始化一次的本地 HashMap 精确查询，无逐键扫描词典或联网请求。原始 0.1.14 样本见 `docs/evidence/0.1.14-performance-after.json`；应在后续 Android 真机上继续监测输入体验。
