# 0.1.12 词汇补充与交付测试报告

日期：2026-10-06。移动端 0.1.12（versionCode 13），Windows 增强补丁 0.1.5（适用于青简 Windows 0.1.4）。iOS 共用词库源码，未编译、未真机验证。

## 本批补词

- 批次02首段新增32个英文词、32组中英对应，落在31个现有拼音候选中文键；32个词此前都没有中文映射。中文候选原顺序不变。
- 收录要求为固定 CET4/6 词表中的词，在固定 ECDICT 与 KyleBing 数据中有完全相同的中文短义和词性，并且该中文词面确实是青简拼音候选。来源和逐词审核结果见 `vocabulary/data/batches/02-reviewed.tsv`、`02-additions.tsv` 和 `02-manifest.json`。
- 127组来源交叉证据中，32组通过逐项审核并加入；85组释义不在拼音候选中，当前无法从键盘实际输入；其余10组因词性或义项证据不足暂缓。没有为了提高覆盖率放宽规则。
- 固定词表映射覆盖率：CET4 从4,660/4,999（93.22%）到4,672/4,999（93.46%）；CET6 从5,326/6,036（88.24%）到5,356/6,036（88.73%）。按当前拼音候选实际可触达统计，分别从4,454到4,466、从5,056到5,086。去重后还有797个四六级词未映射（四级327、六级680，二者有重叠）。这些社区词表统计不代表官方考纲完整覆盖。
- 累计扩词3,660组、2,664个中文键、2,828个英文词面；原有映射和同中文候选顺序保留，每键扩词上限仍为8。32词完整清单与未纳入原因见批次数据文件。

## 性能与包体

同一 Windows 主机的 debug C ABI 对比；18组（6个拼音×3种考试目标），每组180次热态查询。测量包括候选状态、扩词、标签、音标和 JSON 解码，不含系统按键到屏幕绘制，也不是 Android 设备测量。

- 初始化单次样本：193.01ms → 195.19ms。
- 18组 p95 的中位数：2.195ms → 1.826ms；各组 p95 范围从1.252–4.731ms变为1.123–5.251ms。组间有波动，样本不足以宣称变快或变慢；当前结果未显示一致的查询开销上升。
- APK 体积252,266,853字节，SHA-256：`f25b69b1bd78ffcfcc89bd87e4a8056e95541c138fd450ed9d23e01b0f82b753`。相较0.1.11的APK，大小相同；这批映射进入同一精简本地索引，没有把研究用 CSV/JSONL 加进运行包。
- Windows 服务程序11,313,664字节，SHA-256：`e68aa1eabd3689f0e749acd82516d36f9db12d1e9e1c451e1525a8362b1cd703`；音标数据12,208,376字节，SHA-256：`54e2c878989d5e509d4e5683c86fba83722a8d2d64429f0adaa5cea9d6a9323b`。

原始测试输出、APK 元数据和性能样本在 `docs/evidence/0.1.12-*`；词表的来源版本与数据哈希在 `vocabulary/data/batches/02-manifest.json`。
