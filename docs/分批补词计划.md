# 词伴分批补词计划

日期：2026-10-06。当前基线：移动版 0.1.13 / Windows 增强补丁 0.1.6（基于青简官方 Windows 0.1.4）。

## 固定使用规则

用户手动多选四级、六级、专四、专八、托福、雅思。只优先英文译词，中文候选顺序不动；一个词保留所有命中的考试标签，其他译词不删除。界面不显示 A1–C2。各批合并成同一套随包本地索引，用户无需逐批导入。

## 数据构建与统计口径

1. 复用已固定版本、校验过许可和 SHA-256 的 ECDICT、KyleBing 词表；新增来源另行记录，不混用未说明版本的下载文件。
2. 分离原释义、已发布扩词、自动核对新增、人工核对新增。原译词和已发布扩词保持；重复英文词按完整词面合并，词性和来源仍可追溯。
3. 自动扩词只用完整短中文词义，不从长解释截取词根或任意子串。WordNet 同义验证和明确人工核对是不同的证据，报告中分别计数。
4. 覆盖率指固定社区考试词表中“至少有一组中文—英文释义映射”的去重英文词比例；原词、新增、短语、缺失音标分别计数。此指标不能等同全部词都已在实际拼音候选中验证。
5. 无安全映射的词留下原因和候选释义，进入下批；不把仅有标签的词算成新加入可用词。

## 性能与两端交付

运行时只载入精简映射和标签索引，不解析研究 CSV/JSONL；索引一次初始化，按中文精确查询，显示层保持紧凑。每批对相同拼音、相同目标、相同构建方式测量耗时，记录 p50/p95、初始化耗时和包体变化。主机测量明确不当成手机实测。

新增对应先通过共享内核与真实 Windows 服务检查，再构建 Android 包验证新增词、标签、音标和逐条上屏；布局或触屏代码若未改，不为数据更新重复大规模界面测试。iOS 同步共享源码，缺少 Mac 时不声称已编译验证。

发布使用新版本，不覆盖旧安装包；电脑版补丁保留备份和回滚。完整考试覆盖只有在缺口清单逐项处理后才能宣称，专业词包另算。

## 批次01本轮结果

新增2,033组对应，309个此前未映射的英文词。四级映射覆盖率93.22%，六级88.24%；829个去重缺口已记录原因，进入批次02继续处理。共享内核和两端验证详见 [0.1.11测试报告](0.1.11测试报告.md)，数量与统计口径见 [四六级补词说明](0.1.11四六级补词.md)。

## 批次02阶段结果（0.1.12–0.1.13）

批次02累计新增230组中英对应，涉及178个此前没有映射的英文词，分布于220个拼音候选中文键。每组均命中固定四六级词表，并在固定 ECDICT 与 KyleBing 的四六级条目中找到同词、同中文短义和同词性；中文候选面再与固定拼音词库逐字核对。对中文键词性差异、别名及新中文键分别记录人工复核类别，新增记录保留英文义项词性；没有覆盖旧译词。

扩大审计后共找到588组双来源同义项，其中322组所用中文释义不在现有拼音候选面，暂不装入；另有36组词性或义项关系证据不足，保留在逐项审计表中；230组达到纳入条件。拆分 KyleBing 单字段中的并列中文义项后，四级映射覆盖率从93.22%升至94.78%，六级从88.24%升至90.94%；去重未映射词由797降至651。覆盖只表示存在中文映射，不代表当前拼音候选必然可输入；二者分开统计。详见 [0.1.13补词记录](0.1.13四六级补词.md)、[逐项证据与处置](../vocabulary/data/batches/02-evidence.tsv)、[0.1.12首段](0.1.12四六级补词.md) 和 `vocabulary/data/batches/02-*`。
