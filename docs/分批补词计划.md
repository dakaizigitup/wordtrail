# 词伴分批补词计划

日期：2026-10-06。当前工作版：移动版 0.1.17 / Windows 增强补丁 0.1.10（基于青简官方 Windows 0.1.4）。

## 固定使用规则

用户手动多选四级、六级、专四、专八、托福、雅思。只优先英文译词，中文候选顺序不动；一个词保留所有命中的考试标签，其他译词不删除。界面不显示 A1–C2。各批合并成同一套随包本地索引，用户无需逐批导入。

## 当前执行队列

1. 继续批次02：用固定词典与可追溯的 Wiktionary 修订找出精确、可输入的四六级缺词；每段建议约5–100组，按证据量决定，不设最低配额。本轮第二段收录7组并记录 Kaikki 派生候选发现快照哈希，低置信或语义过宽项不进入运行词库。
2. 批次02收尾后切到专四/专八；按两份词表分别计算已有覆盖、拼音可达覆盖和缺失音标，先复用六类共享词库里的现有词义，再筛新增对应。
3. 再处理托福/雅思与专业类别；对短语单独设规则，不把短语子串映射成单词，标签重复项按英文词面去重。
4. 每段都先构建共享内核并验证真实拼音可达、目标标签优先、原中文候选顺序不变、音标齐全和上屏；通过后再更新 Android 与 Windows 包并记录性能/包体差异。

## 数据构建与统计口径

1. 复用已固定版本、校验过许可和 SHA-256 的 ECDICT、KyleBing 词表；新来源逐项固定修订、保留授权记录。不同许可的数据文件单独存放、署名并随包交付，不混用未说明版本的下载文件。
2. 分离原释义、已发布扩词、自动核对新增、人工核对新增。原译词和已发布扩词保持；重复英文词按完整词面合并，词性和来源仍可追溯。
3. 自动扩词只用完整短中文词义，不从长解释截取词根或任意子串。WordNet 同义验证和明确人工核对是不同的证据，报告中分别计数。
4. 覆盖率指固定社区考试词表中“至少有一组中文—英文释义映射”的去重英文词比例；原词、新增、短语、缺失音标分别计数。此指标不能等同全部词都已在实际拼音候选中验证。
5. 无安全映射的词留下原因和候选释义，进入下批；不把仅有标签的词算成新加入可用词。

## 性能与两端交付

运行时只载入精简映射和标签索引，不解析研究 CSV/JSONL；索引一次初始化，按中文精确查询，显示层保持紧凑。每批对相同拼音、相同目标、相同构建方式测量耗时，记录 p50/p95、初始化耗时和包体变化。主机测量明确不当成手机实测。

新增对应先通过共享内核与真实 Windows 服务检查，再构建 Android 包验证新增词、标签、音标和逐条上屏；布局或触屏代码若未改，不为数据更新重复大规模界面测试。iOS 同步共享源码，缺少 Mac 时不声称已编译验证。

发布使用新版本，不覆盖旧安装包；电脑版补丁保留备份和回滚。完整考试覆盖只有在缺口清单逐项处理后才能宣称，专业词包另算。

## 批次01本轮结果

新增2,033组对应，309个此前未映射的英文词。四级映射覆盖率93.22%，六级88.24%；829个去重缺口已记录原因，进入批次02继续处理。共享内核和两端验证详见 [0.1.11测试报告](0.1.11测试报告.md)，数量与统计口径见 [四六级补词说明](0.1.11四六级补词.md)。

## 批次02阶段结果（0.1.12–0.1.13）

批次02累计新增230组中英对应，涉及178个此前没有映射的英文词，分布于220个拼音候选中文键。每组均命中固定四六级词表，并在固定 ECDICT 与 KyleBing 的四六级条目中找到同词、同中文短义和同词性；中文候选面再与固定拼音词库逐字核对。对中文键词性差异、别名及新中文键分别记录人工复核类别，新增记录保留英文义项词性；没有覆盖旧译词。

扩大审计后共找到588组双来源同义项，其中322组所用中文释义不在现有拼音候选面，暂不装入；另有36组词性或义项关系证据不足，保留在逐项审计表中；230组达到纳入条件。拆分 KyleBing 单字段中的并列中文义项后，四级映射覆盖率从93.22%升至94.78%，六级从88.24%升至90.94%；去重未映射词由797降至651。覆盖只表示存在中文映射，不代表当前拼音候选必然可输入；二者分开统计。详见 [0.1.13补词记录](0.1.13四六级补词.md)、[逐项证据与处置](../vocabulary/data/batches/02-evidence.tsv)、[0.1.12首段](0.1.12四六级补词.md) 和 `vocabulary/data/batches/02-*`。

## 批次02新增来源小段（0.1.14）

针对剩余651个四六级缺口，从 English Wiktionary 固定修订页中筛查中文翻译；逐条核对译义、词性、现有青简拼音候选、随包音标和本地 ECDICT 短义，纳入15组、15个新英文词，均能由现有拼音候选键面触达，其中四级7词、六级14词（标签有交集）。固定 ECDICT 与考试词表的完整7–12字中文短义交集审计没有找到可加入项，因此没有从长解释截取子串。排除没有精确拼音候选、词义/词性不吻合、缺少音标或表达不合适的候选，不为追数量放宽规则。

Wiktionary 派生数据单独保存为 `wiktionary-expansion.tsv`，不合并进原 MIT/BSD 扩词文件；随包提供贡献者署名、CC BY-SA 4.0 链接、修改说明和15个固定修订链接。完整逐词审校及构建统计见 [0.1.14补词记录](0.1.14四六级补词.md)、[`03-wiktionary-reviewed.tsv`](../vocabulary/data/batches/03-wiktionary-reviewed.tsv) 和 [`wiktionary-manifest.json`](../vocabulary/data/wiktionary-manifest.json)。新增后四级/六级映射率为94.92%/91.17%，仍有636个去重四六级词未映射；按完整拼音候选表重新统计的可触达率为91.78%/87.76%。0.1.13旧报告的90.66%/86.46%只统计2–6字中文短义，口径不同，详见0.1.14补词记录。这是一轮小批补充，不代表四六级词表已完整。

## 批次02新增来源小段（0.1.15）

从固定 CC-CEDICT 中文释义中筛选四六级整词，精确核对 pinned 英文考试标签、固定 ECDICT 词性、青简本地释义键、真实拼音候选和随包 IPA。第一段纳入58组、58个此前无映射英文词，57个拼音候选键；按拼音词频优先达到1,000的候选，低频的66条已人工初审项目保留到下一段，不当作无效或排除。固定 CEDICT 快照的逐行来源、修改方式及 CC BY-SA 4.0 署名见 [0.1.15补词记录](0.1.15四六级补词.md)、[`04-cc-cedict-reviewed.tsv`](../vocabulary/data/batches/04-cc-cedict-reviewed.tsv) 与 [`CC-CEDICT-ATTRIBUTION.md`](../vocabulary/data/CC-CEDICT-ATTRIBUTION.md)。本段后四六级映射率为95.40%/91.98%，精确拼音候选可触达率为92.26%/88.57%；未映射词578个。其余考试类覆盖、固定文件散列和构建数据见 [`cccedict-manifest.json`](../vocabulary/data/cccedict-manifest.json)。这仍是保守小段，社区词表覆盖率不等于官方完整考纲。

## 批次02新增来源小段（0.1.16）

复核上一段暂缓的66条低频候选；这些条目拼音键频率为3–988，全部通过固定快照整词定义、ECDICT 同词性证据、考试标签、本地拼音键、随包音标与每键容量验证。纳入66组、66个新英文词和66个新拼音候选键；低词频只表示中文键较少见，不作为排除理由。第一段58组与本段66组合计124组 CC-CEDICT 派生运行映射。

第二段独立保存于 [`cccedict-expansion-2.tsv`](../vocabulary/data/cccedict-expansion-2.tsv)，来源及逐条核对见 [`05-cc-cedict-reviewed.tsv`](../vocabulary/data/batches/05-cc-cedict-reviewed.tsv) 与 [`cccedict-manifest-2.json`](../vocabulary/data/cccedict-manifest-2.json)。本段后四级/六级映射率为96.04%/92.91%，按精确拼音候选键计算的可触达率为92.42%/88.68%；仍有512个去重四六级词未映射。社区词表覆盖率不代表官方完整考纲；后续从剩余缺口另行审计，不从长释义截取子串。

## 批次02新增来源小段（0.1.17）

对固定 Kaikki/Wiktionary 中文释义快照进行全六类标签审计，经过同词性 ECDICT、精确拼音键和 IPA 过滤，得到87组自动候选、85个不同词面；这只是待人工核对的队列，不直接进入运行库。本段仅纳入7组有明确同义义项、词性和固定 Wiktionary 页面修订支持的映射，覆盖船上→aboard、冬眠→dormant、指引→guideline、先期→premature、加油→refuel、警司→superintendent、空想→utopian。其余语义过宽、语域/地区受限或可能是同形字误配的候选暂不收录。

新增运行文件 [`wiktionary-expansion-2.tsv`](../vocabulary/data/wiktionary-expansion-2.tsv) 与逐项记录 [`06-wiktionary-zh-reviewed.tsv`](../vocabulary/data/batches/06-wiktionary-zh-reviewed.tsv) 独立标注 CC BY-SA 4.0；Kaikki 派生 SQLite 仅用于候选发现，不随包分发，采用词条均链接到固定 English Wiktionary 页面修订。数据审计和输入散列见 [`wiktionary-manifest-2.json`](../vocabulary/data/wiktionary-manifest-2.json) 与 [`all-exam candidate audit`](../scripts/audit_wiktionary_all_exam_gaps.py)。

本段后扩词累计4,004组。四六级中文映射率为96.10%/92.98%，仍有505个去重缺口；按完整拼音候选面统计的可触达率为92.96%/89.56%（包含单字候选，历史0.1.16报告为2–6字键口径，不直接比较）。新增词条均来自现有多字候选，按历史2–6字键口径分别为92.48%/88.75%。全六类映射覆盖率、可触达率和许可边界见本版补词记录；均为固定社区词表统计，不代表官方完整考纲。
