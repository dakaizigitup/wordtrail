# 安卓 0.1.4 系统语音兼容修正

覆盖安装 `wordtrail-0.1.4-debug.apk`，保留词库和学习数据，不需要卸载。本版继续使用手机系统语音，无需云服务账号或 API Key。

本次修正：启动前检查公开、已启用且允许第三方绑定的识别服务；明确绑定所选服务；自动模式下，系统默认配置失效且只有一个有效服务时使用该服务。有多个服务时可手动选择，不会无提示切换到另一家服务；手动选择的服务被删除后会提示重新配置。

旧版把服务器失败、服务断开和客户端启动失败都显示为“服务暂不可用”。新版会保留具体错误、数字编号和实际服务名称，并提供设置、切换输入法和返回键盘入口。

## 手机上怎么操作

1. 安装后打开词伴，向下找到“语音输入”，点“系统语音设置与诊断”。
2. 查看“当前服务”，点“选择识别服务”。有可用服务时选择它；也可跟随系统。
3. 想直接尝试系统联网语音，可关闭“优先设备离线识别”。联网与语言支持由所选服务决定。
4. 返回聊天输入框，切换到词伴，点麦克风。允许麦克风权限及系统服务后说话，点“完成”确认最终结果。
5. 若失败，页面会留下错误码。例如 5 是客户端启动失败，4 是服务器错误，11 是服务断开，9 是麦克风权限不足；这些是类别，不单凭编号判定根因。诊断页显示设备型号、公开服务列表、当前服务、权限及最近一次错误，可主动复制。

诊断不包含聊天内容、录音或密钥。仍无 INTERNET 权限，词伴不自己上传或保存录音；手机系统服务可以联网。

如果设备没有开放可工作的系统识别服务，改启动代码不能制造一个服务。微信输入法能语音输入并不证明它提供了公开的 Android RecognitionService。此时可点“切换输入法”选择微信输入法，用其麦克风录入，再从键盘切回词伴。本版不会调用微信的私有语音接口，也不会自动打开它的麦克风。

本版验证使用 Android 15 模拟器及独立合成识别服务，检查默认配置失效、明确服务选择、错误、取消和输入框安全。**尚未验证用户 iQOO 手机和平板的真实录音识别，不能承诺真机问题已经解决。**

实现依据：[Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)、[RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent)。
