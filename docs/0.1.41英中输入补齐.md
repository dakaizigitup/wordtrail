# Android 0.1.41：英文识词、英中释义和希腊字母

本地测试版，versionCode 42。保留 0.1.40 的键盘布局、九键逐段选拼音、离线语音和个人词频功能。本次未更新或安装 Windows 程序，也未上传 GitHub。

## 修复的缺口

此前 Android 没有向共享引擎传入电脑版使用的英文词表和英中释义表；英文模式逐字直通，也就没有单词候选。现在复用固定的 `english.tsv`（94,568 个词形）和 `glossary-zh.qj`，在本地完成查询，不调用翻译接口。这是单词补全与词典释义，不是整句机器翻译；未收录的专名、词形和释义仍可能没有候选。

| 输入场景 | 操作与行为 |
| --- | --- |
| 中文模式输入 `hello` | 可见英文候选和中文释义，点词输入英文，长按输入第一条中文释义 |
| 英文模式输入 `comp` | 提供 `company` 等补全；点候选接受完整英文词 |
| 英文模式输入 `helo` | 可提供 `hello` 等拼写建议；按空格仍输入 `helo `，不会擅自接受纠错 |
| 查看英文单词 | 点下方释义或下滑打开详情，可看该英文词的音标、考试标签，并选择中文释义上屏 |
| 输入 `lambda` / `lamda` | 首屏加入 `λ`、`Λ`；点选后完整消耗输入串 |
| 输入希腊字母 | `123 → 符号 → 希腊`，24 组字母，可切换大小写，`ABC` 返回字母键盘 |
| 输入 `en` | 增加 `嗯`；需要时展开候选。九键输入 `36` 后选择读音 `en` 同样可用 |

还补充了“嗯嗯”（en en）和“诶”（ei）。新字词以零初始频次加入，保持原有中文候选间的相对次序；经用户选择后可由既有个人词频机制调整。希腊字母以快捷候选处理，不写入中文学习词库。

密码、网址、电话和数字输入框沿用原有直接输入规则；英文候选的中文释义方向不受学习语言选择影响，中文候选仍按所选英语/日语/西班牙语显示译词。英文候选的标签属于英文单词本身，不给中文释义错误标注英语考试等级。

## 覆盖升级为什么原先可能没有新词

旧版本一直解压到固定目录 `data-0.1.4-ipa1`，发现文件已存在就跳过，即使 APK 已带新词库，仍可能加载旧文件。

现在构建时生成包含数据大小和 SHA-256 的 `data-pack.json`；运行时用该清单的内容哈希命名私有数据目录，首次复制核验大小及哈希，再打开词库。新旧数据文件分开，避免覆盖正在使用的内存映射；个人学习文件继续使用独立的 `learning` 目录，不随词库升级删除。

## 验证与范围

发布数据的 Rust 回归覆盖：`嗯` 的全键/九键入口、英文识词与中文上屏、英文补全/拼写建议、大小写、空格不自动纠错、标点与回车、切换学习语言后仍显示中文释义、希腊字母上屏后清空输入。

Android 模拟器检查覆盖：从 0.1.40 原地升级、实际 InputConnection 上屏、详情音标/释义、Greek 面板返回、中英快速触摸输入，以及原有动作键、数字框、删除选区/组合表情、手机/平板九键逐段选音。具体结果和安装包校验见 `docs/evidence/android-0.1.41-*.json`。

验证使用 Android 35 x86_64 模拟器，APK 同时包含 arm64-v8a 和 x86_64。尚未在用户的 iQOO 手机或 vivo 平板上实测，不据此宣称与所有商业输入法全面对齐。中英整句预测、无限专名词库等不属于本次新增能力。

## 数据来源

- 英文词表及英中释义：固定青简 v0.1.4 数据；校验见 `data/manifest.json`。英文词形、词频的分项许可见 `NOTICE.txt`、`data/english-sources` 和上游 `assets/lexicon/05_english/sources`。
- “嗯”的 en 读音核对[教育部重编国语辞典](https://dict.revised.moe.edu.tw/dictView.jsp?ID=10470&la=1&powerMode=0)；新增表只记录字形和拼音事实，没有复制辞典解释。
- 希腊字母名称及字符参考 [Unicode Greek and Coptic](https://www.unicode.org/charts/PDF/U0370.pdf)。支持常用拼写 lambda 和 Unicode 名称拼写 lamda。
