# 词伴 0.1.2 界面更新

安装 `wordtrail-0.1.2-debug.apk` 覆盖旧版，不用卸载，保留原来的词频和学习数据。

## 平板与手机

键盘根据实际窗口宽度和可用屏幕高度调整。宽屏的键区限制宽度并居中，顶部功能按钮保持固定大小，不会在整块平板屏幕上平均拉长。空闲候选区更紧凑；横屏小窗口使用较矮的按键。三套主题仍可切换。

底部从左到右是：123、**中/英**、地球、逗号、空格、句号、回车。中/英按钮用于切换中文拼音和英文直接输入；地球用于选择其他系统键盘，是两个不同操作。按钮内高亮当前语言。密码、邮箱等要求直接输入的字段会禁用中文切换。

大写、删除和回车使用统一线条图标，地球在按钮中居中。英文模式下字母显示当前大小写：点大写键输入一个大写字母后恢复小写，快速双击锁定大写，再点一次取消。

## 候选和读音

候选卡片统一宽度、高度，中文和释义对齐；不会因为英音、美音或发音变体较多而撑开卡片。较长的候选和释义在卡片中省略，详情中可以查看完整释义。

- 点候选中文：输入中文。
- 长按候选中文：输入第一条译词。
- 点 **音标 ▾**，或在候选上向下滑：展开该候选的音标详情，不会上屏文本。
- 在详情中上下滑：查看完整释义、英式/美式音标及多种发音。
- 点 **收起**：关闭详情；继续键入或换页也会关闭，避免显示上一组候选的读音。

苹果键盘源码同步了相同布局和详情交互，但仍未在 Mac/Xcode 上编译或实测。Android 的实际验证记录见测试报告与 adaptive-layout-tests.json。
