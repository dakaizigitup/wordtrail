# 词伴 0.1.12：四六级补词批次02首段

本版新增32个可从现有拼音候选实际输入的四六级词条。选择四级或六级学习目标后，对应英文译词会优先展示；中文候选顺序和原有译词不变。累计扩词3,660组。固定社区词表统计还剩797个未映射词，本版不代表四六级已补全。
