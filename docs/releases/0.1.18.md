# 词伴 v0.1.18 — 2026-10-06

本版新增20组经过逐条核对的四六级词义映射，覆盖四级、六级、专四、专八、托福和雅思标签。新增词从现有拼音候选中输入，保留原中文候选顺序和既有译词；每个新词均有标签与英语音标。

扩词累计4,024组。四六级社区词表的去重未映射词由505降至485，四级/六级映射覆盖率为96.22%/93.27%。窄义项在审校表中单独注明；覆盖率不代表官方考试大纲完整覆盖。

- `wordtrail-0.1.18-debug.apk`：Android 8.0+，支持 arm64-v8a 和 x86_64，包含离线语音模型。
- `wordtrail-windows-ipa-0.1.11.zip`：已安装青简 Windows 0.1.4 的用户可安装；保留备份并提供回滚脚本。
- `wordtrail-0.1.18-source.zip`：对应源码、依赖、词库、许可说明和逐条审校记录。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验和。

新增 CC-CEDICT 派生数据按 CC BY-SA 4.0 独立标注；来源、逐条原文行和审校范围见 [`0.1.18 补词记录`](../0.1.18四六级补词.md) 与 [`CC-CEDICT 署名`](../../vocabulary/data/CC-CEDICT-ATTRIBUTION.md)。

测试范围、桌面实测、查询耗时和 Android 设备验证限制见[测试报告](../0.1.18测试报告.md)。
