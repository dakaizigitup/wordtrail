# 词伴 0.1.13：四六级补词批次02第二段

新增198组中英对应、178个此前未映射的四六级词。批次02累计230组，固定社区词表映射覆盖率升至四级94.78%、六级90.94%；仍有651个去重词未映射。原有中文输入候选顺序和译词均保留，选择的考试目标只影响英文译词优先级。

## 发布附件

- Android：`wordtrail-0.1.13-debug.apk`，versionCode 14，Android 8.0+，arm64-v8a / x86_64；APK签名v2/v3与16KiB ZIP对齐已检查。
- Windows：`wordtrail-windows-ipa-0.1.6.zip`，用于已安装青简官方 Windows 0.1.4 的用户；支持从词伴0.1.1–0.1.5补丁升级，安装时仍需Windows管理员确认，可回滚。
- 源码：`wordtrail-0.1.13-source.zip`，含共享代码、固定数据、依赖与许可；不含签名密钥或工具链。
- 校验：`SHA256SUMS.txt`。

完整数据核查见 [`0.1.13四六级补词.md`](../0.1.13四六级补词.md)，测试及性能范围见 [`0.1.13测试报告.md`](../0.1.13测试报告.md)。没有连接 Android 真机或模拟器；iOS源码未在Mac/Xcode编译验证。
