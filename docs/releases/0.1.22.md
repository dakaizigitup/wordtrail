# 词伴 0.1.22

本版新增2,291组专四、专八、托福、雅思映射，新增1,022个中文拼音键。选择一个或多个考试目标后，对应英文译词优先；中文候选原顺序和已有译词保留。固定社区词表映射覆盖率达到专四97.56%、专八95.85%、托福90.81%、雅思96.20%。托福完整拼音键可触达率为85.16%，仍低于映射覆盖率。

批次11按许可拆分 ECDICT、KyleBing、Chinese Open Wordnet、KOReader、FMLD 与 CC-CEDICT 来源；批次12从有明确词性的 ECDICT 短义扩词，并用固定 CC-CEDICT/Rime ICE 数据核验新拼音键。两批均提供逐词来源记录、SHA-256 和许可说明；自动筛选数据没有宣称逐条人工校对。细节见 [`0.1.22补词记录`](../0.1.22专四专八雅思托福补词.md)。

Android versionCode 为23，版本名0.1.22；Windows 补丁为0.1.15，适用于官方青简 Windows 0.1.4。iOS 共享源码已更新，未在 Mac/Xcode 编译或真机验证。
