# 词伴 Wordtrail v0.1.29

本版同步 Android 0.1.29（versionCode 30）、Windows 0.1.22 补丁和共享词库源码。可在 [GitHub Releases](https://github.com/dakaizigitup/wordtrail/releases/tag/v0.1.29) 下载 APK、Windows 补丁、完整源码包和 SHA-256 校验文件。

## 词汇更新

- 六类考试目标：四级、六级、专四、专八、托福和雅思；目标可多选，同一个英语词保留多个来源标签。选择目标后优先调整英文译词顺序，中文候选顺序不变。
- OpenEtymology CET4/CET6 社区词单合并为5,709个去重词头标签索引；其中247个 CET4 与2个 CET6 归属是此前没有的来源标签。
- 新增6组经过词性、拼音键和英音/美音 IPA 复核的中英译词，覆盖4个英文词头。
- 合并固定社区词表后，六类目标的映射覆盖率均高于90%，拼音可达率均高于90%。这不是官方考试大纲的完整覆盖率；统计与来源限制见[批次29说明](../29-OpenEtymology四六级补词.md)。

## 安装

- **Android**：面向 Android 8.0+、64 位 ARM 手机/平板，内含离线语音模型。旧版使用同一开发签名，可直接覆盖安装；本版开发测试签名，不是 Google Play 正式签名。
- **Windows**：用于已安装官方青简 Windows 0.1.4 的用户。解压后运行 `install.cmd` 并确认管理员权限；脚本先校验哈希、备份现有文件，提供 `rollback.cmd` 恢复。Windows 补丁尚未在所有 Windows 版本、管理员窗口和特殊系统界面验证。
- **iOS**：提供共享词库源码，没有 IPA；编译需要 Mac 和 Xcode。

词单来自社区公开词表，不代表官方考试机构完整大纲或考试成绩。各数据来源、适用许可证和逐条归属随源码及补丁包提供。
