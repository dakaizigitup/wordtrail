# 词伴 v0.1.20 — 2026-10-06

本版将专四、专八、托福、雅思社区词表的第一批中英映射接入 Windows 与 Android 共用词库：新增1,866组对应，分别使专四映射覆盖达到91.45%，雅思达到89.78%，专八为86.45%，托福为78.87%。拼音候选可触达率分别为87.97%、86.09%、82.64%和74.41%。来源与自动筛选边界见[补词记录](../0.1.20专四专八雅思托福补词.md)。

- Android：`wordtrail-0.1.20-debug.apk`，versionCode 21，支持 arm64-v8a 与 x86_64，含离线语音模型。
- Windows：`wordtrail-windows-ipa-0.1.13.zip`，适用于青简 Windows 0.1.4，提供安装、备份和回滚。
- 源码：`wordtrail-0.1.20-source.zip`，含对应源码、精简运行数据、第三方许可和词库来源记录。
- SHA-256：`SHA256SUMS.txt`。

新增数据仅影响译词索引和考试目标排序，不改变中文候选顺序。性能测试以 Windows 共享内核为准；Android 未连接真机时不宣称设备实测。iOS 仅同步共享源码，没有 Mac/Xcode 编译验证。
