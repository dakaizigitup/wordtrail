# 词伴 v0.1.17 — 2026-10-06

本版把7组逐条审校的英语译词接入手机与 Windows 共用词库。每组都能通过现有拼音候选输入，并带词性、考试标签和随包英语音标。选择学习目标后，匹配的英文译词优先显示；中文候选顺序和原有译词保留。

## 下载

- `wordtrail-0.1.17-debug.apk`：Android 8.0+，支持 arm64-v8a 和 x86_64，已包含离线语音模型。
- `wordtrail-windows-ipa-0.1.10.zip`：适用于青简官方 Windows 0.1.4，附安装、备份与恢复脚本。
- `wordtrail-0.1.17-source.zip`：对应的 Android、iOS、Windows 源码、固定依赖、词库与许可材料。
- `SHA256SUMS.txt`：核对以上三个附件。

Android 用户下载 APK 后可覆盖安装同一开发签名的词伴版本；首次使用需在系统设置中启用并切换到词伴键盘。Windows 用户解压补丁后运行 `install.cmd`；`rollback.cmd` 可恢复备份的服务程序和音标文件。

## 本批词汇

新增映射为：船上 → aboard、冬眠 → dormant、指引 → guideline、先期 → premature、加油 → refuel、警司 → superintendent、空想 → utopian。累计扩词4,004组。固定社区词表中，四级映射覆盖率96.10%，六级92.98%；仍有505个去重四六级词没有安全的中文映射。这些统计不代表官方考纲完整覆盖。逐条 Wiktionary 修订链接和 CC BY-SA 4.0 署名随源码及 Windows 补丁提供。

## 验证范围

Rust 工作区测试26项、补词数据测试11项、扩词测试7项、共享接口测试17项、Windows 候选窗口与 IPC 检查327项、安装后的 Windows 检查3项均通过。Android 两种 ABI 构建成功，APK 通过 v2/v3 签名及16 KB对齐检查。本次没有连接 Android 设备或启动模拟器，因此没有新的 Android UI 实测。iOS 源码已同步，但本机没有 Mac/Xcode，未编译。

本机 Windows 共享 C ABI 的9组拼音/目标组合，本次测量 p95 最大8.28 ms、p99 最大9.48 ms；这是桌面主机接口数据，不代表手机性能。详情见[测试报告](../0.1.17测试报告.md)和[分批补词计划](../分批补词计划.md)。
