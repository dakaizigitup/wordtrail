# 词伴 0.1.21

本版为专八、托福词表成员关系和本地译词补充提供独立数据来源，新增136组经过人工复核的中英对应。译词均有固定 ECDICT 与 KyleBing 同词、同短义、同词性证据，并能由本地拼音候选输入且有随包 IPA。

OpenEtymology 的 TEM8、TOEFL 公开词表固定在提交 `7d89f3697abf26e305fe2627f181b692c2c10b28`，上游声明 CC BY-SA 4.0。本项目只提取词头及成员关系；独立标签索引与映射选择表保留署名和许可。词义映射与名单索引分别位于 `openetymology-exam-expansion.tsv` 和 `openetymology-exam-tags.tsv`。

合并社区词表成员关系后的映射覆盖率：专四91.66%、专八87.08%、托福79.25%、雅思90.19%；精确拼音候选可触达率：88.18%、83.27%、74.78%、86.50%。这不是官方考纲覆盖率，拼音可触达也不保证出现在第一页。详见 [`0.1.21专八托福雅思补词.md`](../0.1.21专八托福雅思补词.md) 与 [`0.1.21测试报告`](../0.1.21测试报告.md)。

Android versionCode 为22。Windows 增强补丁升至0.1.14。iOS 同步共享词汇内核，未在 Mac/Xcode 编译或真机验证。
