# Wordtrail 0.1.23

This release extends the existing English exam glossary and makes more of its Chinese translations reachable by pinyin. It does not reorder the original Chinese candidates or replace existing English senses.

Batch 11–12 add 2,291 English-to-Chinese exam mappings across CET-4, CET-6, TEM-4, TEM-8, TOEFL and IELTS. Batch 13 adds 407 frequency-zero pinyin entries for Chinese glosses already present in the runtime dictionary. Their readings are uniquely supported by pinned CC-CEDICT and/or Rime ICE phrase entries. No English translations are added in batch 13.

| Exam list | Mapping coverage | Pinyin reachability |
| --- | ---: | ---: |
| CET-4 | 98.64% | 97.74% |
| CET-6 | 97.61% | 96.67% |
| TEM-4 | 97.56% | 96.15% |
| TEM-8 | 95.85% | 94.05% |
| TOEFL | 90.81% | 90.01% |
| IELTS | 96.20% | 94.91% |

Mapping coverage means that the fixed community word list contains at least one English-to-Chinese mapping. Pinyin reachability means that the whole Chinese gloss has a local pinyin key. These figures do not represent official complete syllabi and do not promise that a low-frequency gloss appears on the first candidate page. The corrected baseline includes single-character input candidates and previously existing senses unlocked by new pinyin keys.

Android is version 0.1.23. The Windows enhancement patch is version 0.1.16 and requires the official Qingjian Windows 0.1.4 install. It updates the derived runtime pinyin dictionary alongside the server and pronunciation pack; the installer verifies the source dictionary and keeps a rollback copy. The iOS source is included but has not been compiled or tested on a Mac/Xcode environment.
