# Wordtrail v0.1.38 · Android 键盘更新

本版发布 Android 0.1.38（versionCode 39）、完整对应源码和 SHA-256 校验文件。已有同签名词伴版本可直接覆盖安装，保留设置与本机学习记录。

从 0.1.30 升级后可使用：

- 九键与26键切换，九键左侧筛选读音，右侧删除、重输。本机学习常用选词与读音，私密输入不学习。
- 候选右侧箭头展开网格，按键区域隐藏，面板保持等高；候选和读音分别滚动，支持翻页及返回键盘。
- 音标与全部词汇标签在可滚动详情里查看；手机、平板、横屏与大字体布局重新适配，修复候选裁字。
- 布局、键盘高度、底部留白设置立即生效。“加高”调整按键高度，“抬高”调整按键位置。
- 九键长按选择大小写字母和数字，例如 `M N O 6 m n o`；26键长按提供 `Q 1 q`、`L ? l`，滑选后松手直接输入所选字符。
- 打字、点选中文候选和长按选字确认有触感反馈，遵循系统设置。

保留英/日/西语候选、英语音标、六类考试及六类专业目标标签和本机离线语音。词库包含已完成的第38批信息术语补充：4组映射、52个来源词头关系，来源与审校表随源码包提供。

验证记录：9项即时设置、59项长按手势、44项手机/大字体/平板/横屏布局、6组快速触屏输入通过；选字震动已在系统日志确认；26键大小写和数字/符号选择验证36项通过；移动 Rust 7项通过。Android APK v2/v3签名与16KB对齐已验证。不同品牌真机覆盖仍有限，iOS源码未在 Mac/Xcode 编译验证。

本次发布 Android 更新。Windows 已发布的音标与词汇补丁继续使用 [0.1.23 下载](https://github.com/dakaizigitup/wordtrail/releases/download/v0.1.30/wordtrail-windows-ipa-0.1.23.zip)，仓库同时保留后续 Windows 开发源码。

完整实现、截图、机器可读测试证据和下载校验说明见 [0.1.38 发布说明](https://github.com/dakaizigitup/wordtrail/blob/main/docs/0.1.38发布说明.md)。源码包不包含工具链、签名私钥、用户输入记录或个人安装备份。
