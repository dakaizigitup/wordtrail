# 安装与测试指南

## 安卓

当前移动版为 0.1.12，使用暖色小书灵图标。覆盖安装后保留本机设置和词频；不要先卸载旧版。

安装包名称 `wordtrail-0.1.12-debug.apk`，约 250 MB，已包含离线语音模型，应用名称“词伴输入法”。它是本机签名的测试版，与青简 Windows/macOS 官方包是不同应用。建议预留约 1 GB 空间，包含安装包和首次使用生成的模型副本。

1. 把 APK 传到手机（USB、自己的文件传输工具均可），在文件管理器打开安装。如系统询问，请只为此次打开 APK 的文件管理器允许安装。
2. 打开词伴，按“① 启用词伴键盘”，启用“词伴输入法”。系统会显示第三方输入法的通用提示。
3. 返回词伴，点“② 切换到词伴”，选择词伴。也可从系统键盘切换按钮选择它。
4. 点应用里的试打框，使用词伴屏幕上的字母键输入 `nihao`，此时不要先按空格。
5. 查看“你好”候选和下方英文译词。点“你好”输入中文；重新输入 `nihao`，长按“你好”输入 `hello`。点候选右侧小箭头 ▾ 或在候选上向下滑，展开完整释义和英音/美音；详情可上下滚动，点“收起”关闭。
6. 点“EN 译词”切换日语，显示 JA 后仍输入中文拼音；再次点则切换 ES 西班牙语，下一次回到 EN。

考试词汇：在首页“英语学习目标”中手动多选四级、六级、专四、专八、托福或雅思，命中的英文译词优先显示，同一词可带多个标签。中文候选顺序和原有译词不变；标签表示社区词表收录，不等于考试成绩或官方完整考纲。A1–C2 不在当前界面显示。说明见 [0.1.8 词汇目标](0.1.8词汇目标.md)。

常用操作：点底部“中/英”切换输入模式；地球用于选择其他系统键盘；空格选当前页首候选；回车在拼音未完成时上屏原始字母；候选条可左右滑动，“‹/›”切换候选页；“123/ABC”切换数字符号布局；长按删除连续删除。

0.1.6底栏为 `123｜中/英｜逗号｜地球｜空格｜句号｜回车`，逗号靠近左手拇指，地球与逗号换位。字母、数字、常用标点和空格按下即响应，快速输入时首次展开候选不再改变输入窗口尺寸。

换肤：点键盘上的 ◐，选择“青绿”“粉紫”或“深色”，立即切换并保留当前未完成拼音。也可在词伴应用的“换一种心情”卡片中选择主题。选择保存在本机，下次使用继续沿用。

语音：默认选“本机离线”。点顶部麦克风，首次按系统提示授权，返回键盘后再次点击。第一次会准备随包模型，稍等提示“请说话…”。中文 / 英文跟随底部“中/英”，点“完成”停止并识别上屏，点“取消”丢弃录音和临时文字。每次最长 30 秒，未完成拼音、密码和数字输入框不启动语音。无需另行下载模型或注册服务。0.1.6 已修复完成时的低音量/长静音误判；最终为空时保留本轮有效预览。详细说明见 [0.1.6 更新](0.1.6词汇分级.md)。只有主动选择“系统语音”时才使用手机的公开识别服务，该服务可能联网；没有服务的 vivo 设备保持“本机离线”即可。

收起键盘：点工具栏最右侧向下箭头。录音中点击也会取消录音并收起。底部地球键仍用于切换输入法。

如果仍看到系统输入法的候选框，说明当前键盘没有切换到词伴。手机上应看到词伴自己的“中/英”“EN 译词”和候选条。

橙色/灰色只表示上游熟悉度规则下的展示或使用次数，不是语言掌握程度测试。此版没有学习统计页，暂不能按列表查看全部已熟悉词。

可试打的检查项：

- `nihao` → 你好 / hello；`xuexi`、`yingyu` 能显示双语候选。
- `ran shao`（连写输入）→ 燃烧 / combustion；`xian dai hua` → 现代化 / modernize；这些补充词需在首页勾选四级或六级后优先。
- 空格与点击候选可以输入中文；长按候选可以输入第一条译词。
- 输入 `shi` 后候选翻页，再选候选。
- 切换聊天输入框时，前一输入框的未完成拼音不会带到新输入框。
- 切换 EN 直接输入英文、数字和标点，再切回中文。
- 关闭网络后仍可查询释义。
- 保持“本机离线”并断网，分别试用中文和英文；确认点取消或向下箭头后不留下临时文字、麦克风停止。

当前 APK 支持 Android 8.0+ 的 arm64-v8a 和 x86_64；未包含 32 位 ARM 架构。源码包保留重编译脚本。卸载应用会删除本机词频和熟悉度；测试阶段如需保留数据请不要卸载重装。

## 苹果

当前交付为 `ios/` 源码和 `scripts/build_ios.sh`，没有可直接安装到 iPhone 的 IPA。

在 Mac 上安装 Xcode、Rust、Python 3 和 XcodeGen，然后运行构建脚本。它先编译三种 Rust 目标并生成 XCFramework，再生成 Xcode 工程和编译模拟器应用。打开工程，为宿主应用及键盘扩展设置自己的 Signing Team；使用真机时改为自己的唯一 Bundle Identifier，扩展标识保持为宿主标识的子标识。

安装后：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 词伴。在输入框中长按地球键选择词伴。当前无需开启“允许完全访问”。密码框及某些应用会切回系统键盘。

苹果分级源码已同步，仍未在 Mac 上编译或实测，具体状态和待验证项目见测试报告。

苹果键盘源码包含同样三套主题，点键盘上的 ◐ 选择。宿主应用中的主题按钮用于应用外观预览；键盘主题在键盘中单独选择，仍无需完全访问。

## 0.1.2 候选和音标说明

候选统一尺寸，英语第一条释义有数据时，点候选右侧小箭头 ▾ 或下滑候选，在详情区查看对应单词、英音和美音。独立音标词典不修改原译词；长按上屏仍是 `hello`。缺词或缺地区数据不会猜测，没有发音音频。原始来源保留多种发音，并不根据词性判断发音。手机和平板布局及操作见 [界面更新说明](0.1.2界面更新.md)。

Windows 安装、切换输入法与恢复原版步骤见 [电脑版音标补丁说明](电脑版音标补丁.md)。
