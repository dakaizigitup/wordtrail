# 0.1.16 四六级补词：CC-CEDICT 低频候选段

本段把上一批暂缓的 **66 组低频中英对应** 纳入运行词库，涉及66个此前未映射的英文词和66个已有拼音候选键。拼音词频为3–988；这里的“低频”描述汉语输入候选的词频，不表示英语单词难度。

## 逐项筛选

每条都通过固定 CC-CEDICT 快照的整词英文释义核对，中文简体词面与本机拼音候选键完全一致；英文词命中本地六类考试标签并有随包英美音标；词性以固定 ECDICT 条目交叉核验。66个键均经过真实 Windows 候选窗口查询、译词轮换及精确上屏验证。中文候选顺序和已有译词保持不变，选择考试目标只影响英文译词排序。

逐条来源行、CC-CEDICT 原释义、拼音、词性证据和人工义项说明见 [`05-cc-cedict-reviewed.tsv`](../vocabulary/data/batches/05-cc-cedict-reviewed.tsv)。独立运行数据为 [`cccedict-expansion-2.tsv`](../vocabulary/data/cccedict-expansion-2.tsv)，清单记录输入版本、散列、筛选规则和覆盖率：[`cccedict-manifest-2.json`](../vocabulary/data/cccedict-manifest-2.json)。该文件仅2,939字节，SHA-256 为 `9fe002674813b6c235b6d5dedb008f21bc008a6422860c4e3513d8fe006064a5`。
