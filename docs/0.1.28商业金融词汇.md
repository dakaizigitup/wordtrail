# 商业金融词汇第三段（0.1.28，批次18）

这一批接入美国消费者金融保护局（CFPB）2024年3月公开的中英金融术语表。词表共81页，项目固定保留文本快照及 SHA-256，来源许可边界和处理方式见[CFPB署名说明](../vocabulary/data/CFPB-ATTRIBUTION.md)。

筛选后得到249条同时满足本机拼音可达、英语本机音标存在、ECDICT中文短义与词性可交叉核对的候选行；合并词性重复后为246组唯一中英对应，其中223组已有或新增可用映射，覆盖这部分筛选候选的90.65%。逐项审核接受67组新映射，其中13个是此前不在本地运行译词里的英文词头；其余映射为已有英文词增加更贴近消费金融/法律语境的中文入口。另有211个词面获得 CFPB 金融词表成员标签，其中193个是新增商务分类归属。候选行中，158条精确映射已存在，2条受每键扩词上限约束，22条未完成金融语境逐词判断，明确留待下一批。90.65%只针对拼音、IPA、ECDICT三项筛选都通过的246组对应，不是整份81页 CFPB 词表的覆盖率。

新增例子：减轻→abatement、废除→abrogate、违约→default、透支→overdraft、汇款→remittance、受托人→fiduciary、结算→settlement、公用事业→utilities。对于没有 ECDICT 同义项、没有本机音标、中文候选不可输入或语义过泛的词，没有强行加入。

运行时只载入54行扩词和208行词表标签；81页源文本、候选表与解释不进入按键查询。标签索引仍是一次初始化后的哈希查询，中文候选顺序不变；新增译词仅参与用户选择的“商务”优先排序。该 CFPB 子集不是完整金融教材、会计/证券/法律专业词库覆盖率，也不能据此宣称金融词汇达到90%。下一段将继续寻找范围更专门、授权清楚且带可输入中英对应的数据源。
