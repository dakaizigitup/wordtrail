# 0.1.20 专四、专八、托福、雅思词汇第一批

本批将 ECDICT 与 KyleBing 的固定社区考试词表作为来源，筛选英语词、考试标签、完整短中文义项、词性、现有拼音候选和随包音标均有记录的条目。共新增 **1,866 组中文—英文对应**，覆盖 **1,866 个新映射英文词** 和 **1,555 个中文拼音键**。数据为自动交叉筛选结果，未逐条人工审校；来源、固定提交、SHA-256 和选入规则见[来源说明](../vocabulary/data/EXAM-TARGETS-ATTRIBUTION.md)与[批次清单](../vocabulary/data/exam-target-manifest.json)。

| 社区词表 | 本批新增词 | 映射覆盖率 | 精确拼音候选可触达率 |
| --- | ---: | ---: | ---: |
| 专四 | 220 | 91.45%（3,969/4,340） | 87.97%（3,818/4,340） |
| 专八 | 1,150 | 86.45%（10,729/12,410） | 82.64%（10,256/12,410） |
| 托福 | 1,018 | 78.87%（9,633/12,213） | 74.41%（9,088/12,213） |
| 雅思 | 477 | 89.78%（5,887/6,557） | 86.09%（5,645/6,557） |

“映射覆盖”表示词库里至少有一个中英对应；“拼音可触达”要求中文键同时存在于固定青简拼音候选表，实际使用时仍可能需要翻页。两项统计都基于固定社区词表，不代表官方完整考纲；社区词表本身也可能有遗漏或分类差异。

本批不改中文拼音词库和中文候选排序。考试词条仍按用户选择的目标优先，原译词保留，同一个英文词可以保留多个考试标签。选入数据分别存放在 `exam-target-ecdict-expansion.tsv`（MIT）和 `exam-target-kylebing-expansion.tsv`（BSD-3-Clause），没有把两种许可合并。当前覆盖离用户提出的约90%目标仍有差距：专四已超过目标，雅思差约15个映射词；专八还差约440个，托福还差约1,359个。下一段优先处理专八和托福，并继续单列可由拼音实际触达的比例。
