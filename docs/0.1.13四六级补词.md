# 0.1.13 四六级补词：批次02第二段

Android 0.1.13（versionCode 14）和 Windows 补丁 0.1.6 同步使用扩充后的本地词库；iOS 仅同步共享源码，未编译或真机验证。

本版新增 **198 组中英对应，涉及 178 个此前没有中文映射的四六级词**。连同 0.1.12 首段，批次02累计新增230组，覆盖220个可由拼音键入的中文候选键。每组都命中固定的四级或六级社区词表，在固定 ECDICT 和 KyleBing 数据中逐项匹配到同一英文词、同一完整中文短义和同一词性，并且中文键存在于固定青简拼音候选表。164组经人工确认，属于中文候选词性与英文义项词性不同；31组是来源吻合但自动同义词校验漏检的别名；另有3个经核验的新中文键。首段的32组保留。原译词和中文候选排序不变。

词表统计只表示至少存在一组中文映射，不代表官方考纲完整收录，也不等于所有映射都能用当前中文拼音键直接触达。四级、六级有大量重复词，去重并集单独统计。考试标签可与专四、专八、托福、雅思标签共存；用户勾选目标后只调整英文译词优先级。

累计扩词表现有3,858组对应、2,779个中文词面、2,974个不同英文词面，共108,602字节。运行包只携带精简映射与标签数据，不携带研究用 CSV、JSONL 或 WordNet。

## 处置与来源审计

修正了 KyleBing 把多个短义放在同一个字段时未拆分的问题。固定数据中得到588组双来源同义项；322组对应的中文词面不在拼音候选表，暂不加入；36组没有通过当前词性/义项关系门槛，继续留在审计记录；230组通过规则或人工逐条复核后加入。逐项列出的英文词、中文义项、来源、词性、拼音键、拼音词频及处置理由见 [`02-evidence.tsv`](../vocabulary/data/batches/02-evidence.tsv)。审核输入和固定数据文件 SHA-256 见 [`02-manifest.json`](../vocabulary/data/batches/02-manifest.json) 与 [`expansion-manifest.json`](../vocabulary/data/expansion-manifest.json)。

新增对照及唯一英文词清单分别保存在 [`02-additions.tsv`](../vocabulary/data/batches/02-additions.tsv) 和 [`02-pending.json`](../vocabulary/data/batches/02-pending.json)。尚缺的651个去重词和没有可输入中文键的词还需要后续处理；批次02仍在进行中，本版不宣称四六级已补全。下一阶段优先审查缺失词中可安全由现有候选触达的别名与短义，再决定是否需要补充拼音中文键。
