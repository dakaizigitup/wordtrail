新增对应 TSV 为 42,147 字节：1,595 组对应、1,307 个中文词条、1,539 个英文词，其中 615 个英文词在实际原始全表中完全没有。重复运行固定数据构建输出 SHA-256 一致：`a066f4daf78372fd3aac9eda2c83167aa8d00429ef85fc6348524d319aa7c7f4`。每个中文词最多新增 8 条，保留所有原译词。

实际例子：六级目标下“一家人”由 family 优先变为新增 household 优先，中文顺序不变；长按和译词按钮都输入 household。“放弃”保留 give up / abandon，滚动到新增 relinquish 后可单独输入。Windows 一行仍显示两条，用 Ctrl+Alt+序号轮换，并以原快捷键输入当前看到的对应词；新拼音或改变目标后恢复目标排序。

熟悉度只计候选行实际显示的译词，避免尚未展开的新增词被提前标成“熟悉”。常用词映射单独审阅，其余经过精确中文/词性匹配、WordNet 拼写与同义校验，但多义歧义仍可能存在，不能视为完整人工审校词典或完整考试范围。

## 性能范围

Windows 主机 debug DLL，通过 C ABI 使用真实原词库、扩词、考试标签、音标与 JSON 解码。测放弃/重要/一家人，以及无目标、六级、六类全选共九组，各预热 40 次再测 300 次；p95 约 2.70–6.59ms。[完整记录](evidence/0.1.10-performance.json)。这是主机查询耗时，不是手机触屏或端到端延迟。

快速点击以真实模拟器触摸注入，并等待原生队列处理完后核对拼音，验证不丢字；不保证所有真实手机的响应时间。未进行本轮手机/平板真机验证。语音实现没有更换，原模型和语音库逐字节保留；本轮不重新评价语音识别准确率。
