# 安卓 0.1.3 语音输入

安装 `wordtrail-0.1.3-debug.apk`，直接覆盖 0.1.2，不需要卸载。此次只新增安卓语音输入；苹果键盘源码保持 0.1.2 的布局和音标功能。

1. 切换到词伴，点顶部麦克风。首次使用按系统提示允许麦克风，返回键盘后再点一次开始。
2. 默认优先尝试 Android 12+ 的设备离线识别。手机是否具备该服务、是否安装了中文或英文语音包，以手机系统为准。
3. 如果设备离线服务缺失或不能识别当前语言，会提示使用系统语音服务。点“使用系统语音”后才开始；该服务可能联网处理录音。录音时仍显示“可能联网”。
4. 点“完成”停止录音并等待最终文字；点“取消”丢弃此次识别。系统服务也可能自行判断一句话结束并返回结果。
5. 识别中的文字仅在键盘中预览，最终结果才插入当前输入框。切换输入框或隐藏键盘会取消识别。

底部“中/英”决定语音语言：中文模式请求普通话 `zh-CN`，英文模式请求英语 `en-US`，与旁边学习译词的 EN/JA/ES 设置相互独立。服务是否支持这些语言以设备为准。已有未完成拼音时，请先选词或清空拼音再点麦克风；密码和数字输入框关闭语音入口。

“允许系统语音服务（可能联网）”在词伴应用的“语音输入”卡片中可随时关闭。允许后会记住选择，仍然优先设备离线识别；需要重新使用系统服务时不重复询问，录音界面继续保留提示。

词伴仍没有 INTERNET 权限，拼音、释义、音标和本地学习不需要网络。系统识别服务属于另一应用，可以通过自己的网络权限联网，因此不能把系统语音输入承诺为完全离线。词伴不保存录音文件，也不自行上传录音。

如果提示“未检测到系统语音服务”，点“语音设置”检查手机是否安装并启用识别服务。部分国产手机没有向第三方应用开放可调用的系统识别服务；即使自带输入法有语音，也不一定能被词伴调用。当前版本不内置替代识别模型。

实现依据：[Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)、[RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent)。

本机验证采用 Android 15 模拟器和单独的测试识别服务，检查权限、系统回调与输入框操作；不代表真实录音识别准确率。手机上的中文识别、麦克风音质、离线语言包和联网服务仍需真机试用。
