# 0.1.25 计算机术语第二段

日期：2026-10-07。批次15以一个固定修订、明确采用 CC BY-SA 4.0 的计算机术语对照表为来源。用户可用“计算机”目标优先显示这些英文译词；原中文候选顺序不变。

## 本段结果

| 项目 | 数量 |
| --- | ---: |
| 固定上游主题表 | 28 份 |
| 有拼音候选、音标和 ECDICT 词性依据的映射候选 | 28 组 |
| 人工接受 | 26 组 |
| 人工排除 | 2 组 |
| 其中此前未进入英文运行词面的词头 | 5 个 |
| 依据源码逐词对应新增的已有词头分类 | 按 61 个唯一英文词面生成独立计算机标签索引 |

两条 `value → 变量/常量` 候选均排除。源条目的组成对应分别写为 `variable quantity` 与 `constant quantity`，并不支持 `value` 作为精确译词。其他接受项保留了章节语境，例如 `schema → 模式` 只作为数据库词义，`level → 关卡` 只作为游戏词义，`channel → 声道` 只作为音频词义。

本段有26组新增中文—英文对应；其中5个是此前运行词面没有的英文词头，其余是在已有英文词头上新增可输入中文入口。该区分避免把标签增加或同词新增释义误报为新单词数。

新增英文词头为 `iteration`、`latency`、`searching`、`typeface` 和 `widget`。

## 接入与质量边界

术语表直接提供英汉术语关系；ECDICT 用来确认目标词的存在和词性，词条自带的组合对应关系用于识别明显错配，英语音标必须已存在于本地英音或美音表。中文键必须已经出现在真实拼音候选表中，每个键也要留在8条扩词上限内。现有精确对应只有在英文成分与目标词面完全相符时才打上“计算机”标签。

该数据集是一个社区计算机科学术语对照表，不是完整计算机专业词表或课程考纲。标签数不代表专业覆盖率；本段从上游可输入条目中筛出有音标的单词，并经过逐条接受/拒绝决定。短语和缺少随包音标的词暂未作为新增候选。

来源、许可、固定提交和逐文件校验记录见 [`CJK-COMPSCI-ATTRIBUTION.md`](../vocabulary/data/CJK-COMPSCI-ATTRIBUTION.md)、[`cjk-compsci-manifest.json`](../vocabulary/data/cjk-compsci-manifest.json)、[`15-cjk-compsci-reviewed.tsv`](../vocabulary/data/batches/15-cjk-compsci-reviewed.tsv) 与 [`15-cjk-compsci-evidence.tsv`](../vocabulary/data/batches/15-cjk-compsci-evidence.tsv)。运行数据由 [`build_cjk_compsci_batch.py`](../scripts/build_cjk_compsci_batch.py) 离线复建。

Android 0.1.25 会包含这批共享词库数据。Windows 版的核心、标签和设置源码同步更新，但本轮不安装电脑版补丁；业务与医学词汇继续另找许可明确的来源分批补充。
