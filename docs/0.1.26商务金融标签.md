# 0.1.26 商务金融标签（批次16）

日期：2026-10-07。Android 0.1.26 / versionCode 27；Windows 词汇与音标源码补丁 0.1.19。Windows 本轮只编译验证，不安装。

## 本批结果

使用 [EDM Council FIBO 金融本体](https://github.com/edmcouncil/fibo) 的固定 MIT 许可快照，筛选能由当前拼音候选触达的英文单词，并逐条查看类标签和定义。87个候选中接受75个商务/金融标签归属，排除12个；其中72个是给已有词条增加商务标签，3个此前已有该标签。

这是**标签批次**：没有新增英文词头，也没有新增中文—英文映射。候选和原有译词保持不动；用户选择“商务”后，命中的英文译词参与优先排序。若一个词另有考试、计算机或医学标签，各标签并存。

标签索引编译进共享词库，启动时一次加载为哈希表；候选查询只需查几个英文译词的标签并稳定排序，不读取 RDF、候选审校表或网络资源。该方案让金融本体提供的审核证据不进入键入热路径。
