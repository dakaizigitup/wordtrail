# 安卓 0.1.6：自动分级、语音完成与快速点按

覆盖安装 `wordtrail-0.1.6-debug.apk`，不用卸载，保留学习记录、主题和离线语音模型。仍支持收起箭头、手机约5个/平板最多9个候选、三套主题。

## 分级不需要逐词设置

英语译词自动查询随包 CEFR 参考词表，默认显示小标签；不需要下载词表、登录或联网。词伴首页“英语词汇分级”中的“候选显示英语等级”开关只控制候选标签，默认开启。关闭后，点小箭头仍可查看等级详情。

| 标签 | 简要说明 |
|---|---|
| A1 | 入门 |
| A2 | 基础 |
| B1 | 中级 |
| B2 | 中高级 |
| C1 | 高级 |
| C2 | 高阶 |

例如 `hello → A1`；宝贝的两条译词 `baby → A1`、`darling → B2` 分别标注。候选小标签只对应第一条英文译词，展开详情查看其他译词，中文选词顺序和上屏文字不受等级影响。橙/灰色继续表示熟悉度，等级标签使用主题强调色。

参考表包含8,845个词，来源是 CEFR-J Wordlist 1.5（A1–B2）和 Octanove Vocabulary Profile C1/C2 1.0。大小写及首尾空白归一化，按整条译词查询，不拆短语或猜变形词等级。同一拼写多个词性时，上游表取最低等级，故这里是词表参考，不是每个义项的精细难度判断。

词表没有的条目，详情显示“未收录（不代表难度）”。例如当前表没有 allocate，不能因此认为它简单、困难或不属于某个考试。日语、西语不显示英语 CEFR 标签。

这是英语词汇参考分级，不是个人水平测评，也不等于完整六级或雅思词库。暂时没有六级、雅思目标筛选、按等级调整译词优先级或分级学习统计。

## 手机语音：已经识别出来，点完成却报没听清

0.1.5 的完成逻辑用整段录音平均音量做拦截，较轻的人声或长停顿可能被判成“没听清”；最终识别为空时也没有保留已经识别出来的预览。

0.1.6 在预览、完成两条路径使用同样的声音片段处理，保留短上下文，去掉较长的前后静音，避免整段平均音量被静音拉低；新增约0.64MB的 Silero 本机人声检测模型，避免仅放宽音量门槛后把背景噪声交给识别器。完成后优先使用最终结果；为空或解码失败时，保留本次录音已成功识别的最新有效预览。预览缓存来自真实模型输出，不包含“正在准备…”等状态文字。

每次录音使用独立缓存；取消、收起、换输入框会丢弃，会话和输入框检查继续生效。新一轮纯静音不会复用上一轮文字。停止麦克风引起的读取中断不再覆盖正常“完成”状态，最后一个有效读取块会保留。

真实中文 WAV 已构造轻声并补足至30秒的长静音样本，执行交付应用的 Java 完成逻辑和真实原生模型；预览恢复验证由实际预览回调产生文字，再强制最后一轮音频为空，检查保存的预览原样提交。另验证新会话静音、背景噪声和取消。具体结果及转写错误见测试报告。真实手机麦克风效果仍需用户覆盖安装后验证，不能用模拟器替代用户设备实测。

## 逗号位置

底栏改为 `123｜中/英｜逗号｜地球｜空格｜句号｜回车`。逗号移到中/英旁，保持较宽的触摸区域；地球键仍打开输入法选择。

## 快速点按

0.1.5 在无候选与有候选之间改变输入窗口高度，快速触屏测试复现了候选首次展开时漏字。0.1.6 改为稳定的透明输入窗口，键盘固定在底部；仅键盘实际矩形接收触摸，上方应用仍可正常点击。空闲候选区继续完全收起，不留空白占位。

字母、数字、常用标点与空格按下即响应；抬手不再次输入，按键保留涟漪和触感，移除缩放动画。候选仍保留点选、长按译词和滑动详情，不改成按下即提交，以保留滚动操作。实际触屏连续输入结果见测试报告，用户真机仍需验证。
