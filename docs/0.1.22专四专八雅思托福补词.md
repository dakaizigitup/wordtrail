# 0.1.22 专四、专八、托福、雅思词汇补充

本版按批次11与12继续扩展共享中英译词索引。所有新增词保留考试标签和英语 IPA；用户可多选目标，命中标签的英文译词优先，中文候选顺序保持原样。

批次11新增1,592组整词映射及411个新拼音键。来源依许可证拆分为 ECDICT MIT 160组、KyleBing BSD-3-Clause 98组、两源共同命中260组、Chinese Open Wordnet 184组、KOReader/COW 双来源137组、CC BY-SA 4.0来源753组。候选筛选使用固定考试标签、IPA、词性/义项证据、精确拼音来源和每中文键容量上限；它是可复建的自动交叉筛选，并非逐条人工审校。

批次12新增699个此前未映射词及699组 ECDICT 整词短义：专四64、专八308、托福438、雅思112，考试标签之间有交集。词义取自 ECDICT 带词性定义中的完整中文短义。新中文键的拼音仅在固定读音数据有来源时采用：CC-CEDICT 与 Rime ICE 同时收录时，拼音归一化后须完全相同；仅一方收录时，在逐条记录中注明该来源。没有可靠读音的候选不纳入。新增拼音词频设为0，不改青简原词库，也不重排已有中文候选。

合并后的社区考试词表映射覆盖率为：

| 类别 | 已有映射 | 覆盖率 | 完整拼音键可触达 |
| --- | ---: | ---: | ---: |
| 专四 | 4,234 / 4,340 | 97.56% | 4,041 / 4,340（93.11%） |
| 专八 | 11,993 / 12,512 | 95.85% | 11,348 / 12,512（90.70%） |
| 托福 | 11,140 / 12,268 | 90.81% | 10,448 / 12,268（85.16%） |
| 雅思 | 6,308 / 6,557 | 96.20% | 6,015 / 6,557（91.73%） |

“映射覆盖”指存在完整中文到英文译词映射；“拼音键可触达”指该映射的完整中文词面已经有本地拼音候选键。两项不能互换；译词也不保证出现在候选第一页。托福映射覆盖已超过90%，可触达率仍需继续补充。本项目采用固定社区词表统计，不代表官方完整考纲或成绩水平。

来源、许可证和逐词审计记录：

- [`EXAM-TARGETS-ATTRIBUTION.md`](../vocabulary/data/EXAM-TARGETS-ATTRIBUTION.md) 记录固定提交、许可边界和提取方式。
- [`batches/11-exam-target-reviewed.tsv`](../vocabulary/data/batches/11-exam-target-reviewed.tsv) 与 [`exam-target-batch-11-manifest.json`](../vocabulary/data/exam-target-batch-11-manifest.json) 记录批次11的逐词来源和输入/输出 SHA-256。
- [`batches/12-ecdict-new-pinyin-reviewed.tsv`](../vocabulary/data/batches/12-ecdict-new-pinyin-reviewed.tsv) 与 [`exam-target-batch-12-manifest.json`](../vocabulary/data/exam-target-batch-12-manifest.json) 记录批次12的 ECDICT 源行、拼音来源、筛选计数和覆盖率。
- [`pinyin-overlays/`](../vocabulary/data/pinyin-overlays/) 保留逐行拼音来源；对应的 CC-CEDICT、Chinese Open Wordnet、KOReader 与 Rime ICE 许可原文随项目提供。

Windows、Android 共用同一份词汇索引和优先排序内核。本版未在 Mac/Xcode 上编译 iOS 源码。
