# 第 38 批：NAER 信息术语

本批固定國家教育研究院《資訊名詞－高中含以下資訊學術名詞》（政府資料開放平台 dataset 15407）。平台列明提供机构为國家教育研究院，字段包含英文名称、中文名称和来源网站，采用《政府資料開放授權條款》第 1 版。授权允许复制、散布、改作和再授权，并要求标明来源。项目保留完整固定快照、校验和、来源网址与署名，并把繁体中文规范成简体后进行精确匹配。来源与授权记录见[署名文件](../vocabulary/data/NAER-INFORMATION-ATTRIBUTION.md)。

881 条源记录中，59 组同时命中本机 ECDICT 名词义项、英音或美音音标和现有拼音键；它们分布在 52 条源记录中，54 组原本已有映射。其余 5 组逐条审查后，接受 4 组中英映射、排除 1 组，新增 0 个此前没有的英文词头。新增映射为：

- 分割 → partition
- 十进制 → decimal
- 喇叭 → speaker
- 目录 → directory

“流通 → currency”不符合合适的独立译义，因此排除；同一条来源中的“货币 → currency”已有本地映射。

本批另有 52 个英文词头取得 NAER 信息术语来源成员关系，其中 23 个是首次加入“计算机”类别。标签只记录词头出现在该专业术语来源中，不声称它的所有义项都只用于计算机。专业术语没有统一完整分母，因此本批不报覆盖率。

按每条 CSV 记录顺序通过筛选门槛：617 条是多词词组或非单词词头；44 条是单词但本地没有音标；52 条没有本地名词词性释义；107 条没有可精确对应的本地中文名词义；9 条有精确中文名词义但该中文词没有拼音入口；52 条通过全部条件。这样得到的 52/881（5.9%）是本地严格匹配筛选率，不是整份数据集的专业词汇覆盖率；多词条目、别名和缺少本地读音的条目仍未进入运行库。

运行时仅新增 4 组精简映射和 52 行来源标签。原中文候选顺序不变；来源 CSV 不进入按键查询路径。逐项审核、拼音/音标证据、清单和 SHA-256 见 `vocabulary/data/batches/38-naer-information-*.tsv` 与 `vocabulary/data/naer-information-manifest.json`。本批已纳入 Android 0.1.31 安装包、Windows 0.1.24 补丁和配套源码包；当前只生成安装包，尚未安装到设备或电脑。
