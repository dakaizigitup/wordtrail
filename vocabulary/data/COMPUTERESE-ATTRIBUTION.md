# Computerese computer vocabulary source

Attribution: EarsEyesMouth contributors, [computerese-cross-references](https://github.com/EarsEyesMouth/computerese-cross-references), pinned to commit `e92ca7dddf6b8122c7c0807f701fa9e237752506` (2024-11-13). The repository provides an MIT license, preserved at [`sources/computerese-cross-references/LICENSE`](sources/computerese-cross-references/LICENSE). The upstream README snapshot SHA-256 is `3f1fb6fb75fe56546380222d5dc7423e2dd36738852bb583e8d99d475a8435fc`.

The upstream README says some entries are extracted from named books. The batch parser excluded every row carrying a source-footnote marker and every long explanation, retaining 297 short, unfootnoted, one-word English entries as candidate evidence. The filtered source rows are [`sources/computerese-cross-references/filtered-terms.tsv`](sources/computerese-cross-references/filtered-terms.tsv), SHA-256 `82d9001532a8a764981b33e4a43aa243841c212147cd70ac40d2cc0047f84030`. The upstream table does not identify provenance for every remaining item, so it is used only for candidate discovery.

Each runtime addition must also match an exact ECDICT Chinese gloss and part of speech, a real local pinyin candidate, local UK or US IPA, available per-key capacity, and an explicit review. From 75 exact candidates, 62 mappings already existed. We accepted 13 new Chinese-English mappings; all 13 English headwords were already present elsewhere in the vocabulary, so this batch adds no new English headwords. We added 55 new computer-category memberships. The 13 mappings, candidates, per-entry decisions, pinned runtime input hashes, and output hashes are recorded in [`computerese-manifest.json`](computerese-manifest.json), [`batches/20-computerese-reviewed.tsv`](batches/20-computerese-reviewed.tsv), and [`batches/20-computerese-evidence.tsv`](batches/20-computerese-evidence.tsv).

Only the compact mappings and selected category rows enter the runtime index. Raw upstream prose is not bundled into the keyboard lookup. The computer tag changes English translation priority when selected; it does not change Chinese candidate order.
